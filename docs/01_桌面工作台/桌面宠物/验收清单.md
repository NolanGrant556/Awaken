# Desktop宠物验收清单

本清单引用 [产品与架构](产品与架构.md) 和 [包格式与导入](包格式与导入.md)，不维护第二套设计。

## 工程检查

- [ ] `npm run typecheck:desktop` 当前执行通过。
- [ ] `npm run build:desktop` 当前执行通过。
- [ ] `npm --workspace @awaken/desktop test` 当前执行通过。
- [ ] `git diff --check` 通过。

## 数据层与导入

- [ ] dev 与 packaged 都能从各自的 `resources/pets` 导入全部 Awaken 内置宠物，安装后不依赖开发机源路径。
- [ ] 内置宠物经同一 validator 校验并原子复制到 userData，更新内置资源时能更新 Awaken 副本。
- [ ] Codex合法v1/v2自定义包无需转换即可导入。
- [ ] 只扫描 `${CODEX_HOME:-$HOME/.codex}/pets/*/pet.json`，不递归/不读内置包。
- [ ] 导入后移走测试源，Awaken副本仍可用并显示source warning。
- [ ] 自动导入/刷新/Codex侧选择不改变Awaken选择、不自动Wake。
- [ ] invalid manifest、尺寸、绝对/逃逸/symlink路径被隔离。
- [ ] duplicate id稳定保留第一候选并报告冲突。
- [ ] renderer只获得受控 `awaken-pet://` URL。

## 浮窗与动画

- [ ] 透明、置顶、skipTaskbar、空白穿透。
- [ ] 宠物浮窗打开时依次切换浅色、深色和跟随系统主题，宠物周围背景始终透明。
- [ ] 九状态取帧正确；v1/v2都验证rows 0–8。
- [ ] idle慢速循环；非idle三轮后回idle。
- [ ] hover jumping、4px阈值、左右拖动动画、点击聚焦。
- [ ] 首次Wake waving+8秒；同pet不重复；waiting压过welcome。
- [ ] reduced-motion真实系统首帧验证。

## 运行状态映射

- [ ] question/legacy pending state 按当前 projector 映射 waiting。
- [ ] error/cancelled -> failed；running/cancelling -> running；finished -> review。
- [ ] 多thread优先级 `waiting > failed > review > running > idle`。

## 通知托盘

- [ ] TTL为running 3分钟、waiting 30分钟、failed/review 15秒。
- [ ] 点击通知导航thread；running Stop可取消run。
- [ ] waiting没有假“直接回答/审批”动作，需聚焦主窗口。
- [ ] dismiss同turn不重复，新turn可出现。
- [ ] bubble出现/消失不移动pet，不破坏drag/穿透。

## 设置页

- [ ] 当前preview、radiogroup、选择排序和warning准确。
- [ ] Wake/Tuck、热切换、刷新、自动导入开关、打开目录可用。
- [ ] 无选择时Wake禁用；选择不可用不静默换第一项。
- [ ] import failed列表可读。
- [ ] Settings没有把内部local template handler宣称为“创建宠物”。

## 拖拽、缩放与定位

- [ ] 80/112/224px边界、重启恢复。
- [ ] 多显示器拖动、移除display、DPI异常bounds恢复。
- [ ] bubble/resize使用右下锚点，pet不漂移。
- [ ] 空闲窗口不占大透明区域。

## 安全边界

- [ ] 不读目录外、不执行代码、不接受HTML/JS/SVG。
- [ ] 不向renderer暴露路径，不修改Codex。

## 视觉证据

- [ ] Settings > Pets截图。
- [ ] v1/v2 preview和Wake截图。
- [ ] 九状态/左右拖动录屏。
- [ ] bubble出现/消失/导航/Stop录屏。
- [ ] 屏幕四周及第二显示器截图。
- [ ] Windows/Linux关闭主窗口pet退出；macOS关闭窗口驻留、显式退出销毁。

证据必须来自当前HEAD真实Desktop；旧勾选和旧Windows摘要不替代当前验收。
