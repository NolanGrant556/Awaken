# 外观与主题 · 需求文档

用户可以选择浅色、深色或跟随系统，工作台与独立窗口应使用一致的生效主题。

代码、接口和验证方法见[实现方案](实现方案.md)。

## 当前支持

Settings > 外观提供：

- 跟随系统 `system`；
- 浅色 `light`；
- 黑色 `dark`。

字号固定为 Design System 当前 token（阅读正文 `15/24`），窗口缩放仍锁 100%。

左侧栏个人入口弹层依次左对齐展示“外观”“查询用量”“设置”，默认无卡片表面，仅在悬停或键盘聚焦时显示灰色反馈。点击“外观”后在菜单右侧打开小型竖向主题选择窗，可切换 `system | light | dark`，选择后收起；它与 Settings > 外观读取、保存同一份偏好并同步选中状态，不建立弹层局部主题。“查询用量”点击后打开独立用量窗口。

未有偏好时默认 `light`。选择即时应用到主窗口；保存失败时UI回滚到前一偏好并显示错误。

Desktop 设置当前使用覆盖内容窗口的全窗口工作区：保留 Electron 原生窗口 chrome，左侧固定“返回应用”和模型、搜索、记忆、全局规则、外观、宠物、计算机操作、Hook、ACP 等普通功能入口，其中 Hook 的界面标题显示为“钩子”；“已归档”分组标题后是语义固定末项“已归档的聊天”；右侧显示当前设置页。这些入口连同各自图标与分组由 Design System 的 `AwakenSettingsNavItems` 唯一定义，Desktop 直接消费，不自行追加导航条目。Hook 页的配置检查、详情、摘要信任与命令执行边界由 04 域拥有；归档页行为由 [会话归档设计契约](../会话管理/实现方案.md) 拥有；设置框架只拥有导航与容器。它不再套居中 `AwakenDialog`，也没有 backdrop、外层圆角卡片、右上角关闭按钮或底部关闭栏；“返回应用”按钮横向占满侧栏可用内容宽度，整行空白都属于同一个点击热区，按钮与 `Escape` 均关闭设置并恢复到原工作台。

设置工作区的标题、导航、标签、说明和其他控制文案默认不可被鼠标选择，避免双击界面空白时出现网页式高亮；输入框、文本域、可编辑区域和显式 `.aw-text-selectable` 正文保留选择与复制能力。该边界由 Design System 的 `AwakenSettings` 统一实现，Desktop 不为单个设置页重复覆盖。

## 偏好与生效主题

存储偏好类型：

`system` 不是CSS主题值：

- Electron Main用 `nativeTheme.shouldUseDarkColors` 决定窗口backgroundColor；
- renderer用 `matchMedia('(prefers-color-scheme: dark)')` 决定DOM实际主题；
- 系统外观改变时，只有preference=system跟随更新。

## 当前不支持

- 自定义主题/色板；
- 除light/dark外的主题；
- workspace级主题；
- 账号云同步；
- 业务组件级独立主题结构；
- 自动高对比模式开关（依赖系统/现有token表现）；
- 密度档开关；
- 字号倍率开关（固定 100%）。
