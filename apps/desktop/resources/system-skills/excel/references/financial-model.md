# 财务模型细则

仅在财务模型或用户模板没有更高优先级约定时使用。

## 结构

- Inputs/Assumptions、Calculations、Outputs 分层；
- 每个假设有名称、单位、期间和来源；
- 公式引用假设单元格，不直接嵌入增长率、税率等魔法数字；
- 历史期与预测期有清晰视觉区分；
- 场景切换使用明确 selector 和可审计公式。

## 数字格式

- 金额单位进入表头，例如 `Revenue (RMB mm)`；
- 负数使用括号；零显示为短横线；
- 百分比存储为小数并显示 `0.0%`；
- 倍数显示 `0.0x`；
- 年份用文本，避免千位分隔；
- 小数位随业务精度统一，不在同一指标中混用。

## 审查

- 资产负债或流量平衡关系；
- 期初 + 变动 = 期末；
- 收入、成本、利润率和现金流的符号；
- 汇率、税率、单位和期间的一致性；
- 每行预测公式是否连续；
- 敏感性表是否引用正确的输出指标。
