# 最终交付物卡片：验收清单

- [ ] 输入附件的横排、折叠、sticky 和点击行为无变化。
- [ ] 源码、脚本、PPT 自动 PDF/PNG 不进入最终卡片。
- [ ] Word、Markdown、Excel、显式 PDF、PPT 可在最终回答后打开。
- [ ] 失败或取消后仍展示已就绪交付物，并显示准确提示。
- [ ] 4 个以上文件默认前三个，展开/收起可访问。
- [ ] live、关闭重开、历史 replay 的数量、顺序和角色一致。
- [ ] traversal、symlink、越界、目录、缺文件和无默认应用均返回结构化错误。
- [ ] `capture:workbench:vrt` 的 dock、marker、composer 和 follow 无回归。
