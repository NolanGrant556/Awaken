# 协议边界

## 1. 当前支持

Awaken 使用 AG-UI 风格事件承载 run、message、tool、context、Skill、artifact 和主动提问。内部 Agent event 和 SemanticRecord 不是 wire；它们必须经过 mapper/projector 转成 `agui.Event`。

live SSE 与 durable replay 共用 semantic projector。transport cursor、semantic frame seq 和 journal seq 分离，断线恢复不得把 cursor 当业务顺序。

## 2. 内部与 wire ownership

| 层 | owner | 约束 |
| --- | --- | --- |
| Agent/Tool | `src/agentcore`、`src/tool` | 产生 canonical outcome、provider/snapshot/Skill 事实 |
| Journal | `src/runtime` | append-before-side-effect、耐久 kind 和恢复 |
| AG-UI | `src/protocol/agui` | 唯一 wire event/tags/semantic projection |
| Desktop | shared type + reducer/projector | 消费，不发明缺失事实 |

MCP wire、Connector definition 和 Skill frontmatter 不是 AG-UI schema；它们只能通过运行时标准化结果进入 AG-UI。

MCP artifact output 的 base64 bytes/hash/path-field mapping 也不是 AG-UI schema。bytes 由 host adapter 消费，只有 Workspace broker 已提交并复核后的 canonical ArtifactDescriptor/change/receipt 能投影；provider-local path、失败结果或未验证 bytes 不得产生 artifact event。

## 3. A2UI

A2UI 仍是上游参考，不是当前 Awaken Desktop 的生产 UI schema/runtime。当前没有通过 A2UI surface/component tree 驱动 Workbench 的完整链路，不能把 AG-UI event 增量误称为 A2UI 已实现。

## 4. 当前缺口

- 右侧 Inspector 尚未消费 provider/dependency/side-effect 详情；
- 旧 transcript 的审批记录只能作为通用 legacy card/unknown projection 回放，不能恢复为可操作审批；
- A2UI renderer、schema negotiation 和安全 component action 尚未实现。
