# 工具、权限与安全执行验收

## 1. 自动化门禁

最终变更集至少执行：

```bash
go test -count=1 ./...
go vet ./...
npm --workspace @awaken/desktop run test
npm run typecheck:desktop
npm run build:desktop
git diff --check
```

按发布矩阵将 Core cross-build 到 macOS arm64/x64 与 Windows amd64；Windows 还要对七个新工具包执行 `go test -c` 编译。cross-build 只证明编译，不替代 Windows Desktop 实机。

注册快照必须精确包含模型基础工具：

```text
Bash, Read, Edit, Write, Glob, Grep, WebSearch
```

并保留 `artifact_publish`、`trash_file`、`calculator`、`ask_user`、`dependency_install`、`git_remote`、`skill`、`memory` 与 MCP/Connector 动态工具。retired 目录和旧活跃工具名不得进入 `src/` 注册、prompt、recovery、projector 或 runtime 路径；历史 fixture、Journal/Artifact producer 兼容映射可明确保留。

## 2. 七工具专项

### 2.1 Read

- 文本 offset 从 1 开始，默认/上限 2000 行；部分读取也建立宿主文件快照和独立投影回执；只有文件版本与规范化 `offset/limit` 都完全一致的重复读取才返回 `file_unchanged`，同文件不同范围必须返回新内容。
- 以签名识别 PNG/JPEG/GIF/WebP/PDF，不以扩展名伪造媒体成功；图片/PDF 每次都重新校验当前模型能力和 pages/route，不得只凭文件版本返回 `file_unchanged`。
- vision=false 图片明确 unsupported；native-PDF=true 走单个 PDF content part；native-PDF=false + vision=true 走 Poppler 144 DPI 页面图片。
- PDF 不默认 `1-5`：≤10 页可省略 `pages`，>10 页返回 `read_pdf_pages_required`；最多 20 页/次，已知总页数时夹紧越界页；无原生 PDF 且无视觉时返回 `model_pdf_unsupported`（文案要求换模型、禁止 Skill/装包绕过）；非法页码、Poppler/`pdfinfo` 缺失导致的 vision 路径失败、20 MiB 总媒体上限均返回可恢复结构化 Outcome。
- Office/Notebook 二进制明确 `unsupported_media`；readable roots、附件授权、敏感路径与 symlink escape fail closed。

### 2.2 Edit / Write

- `Edit` 和覆盖式 `Write` 都要求当前 thread 成功 `Read` 且 SHA-256/size/mtime/type 未变化；外部改动和同路径竞争失败而不刷新状态。
- `Edit` 默认唯一匹配；重复文本只有 `replace_all=true` 可替换；结果有匹配数、canonical diff 和更新摘要。
- 新 `Write` 无需预读且为 UTF-8；覆盖保留已知编码/BOM、CRLF/LF 和 mode；未知/二进制编码拒绝。
- 同目录临时文件 + fsync + 原子替换；失败不产生 change/Artifact，成功刷新读取状态。
- `Edit`/`Write` 永不自动发布 Artifact。

### 2.3 Bash

- 当前用户 no-rc shell、真实 cwd/stdout/stderr/exit/timeout/truncation；默认 120 秒、最大 600 秒。
- thread cwd 互相隔离且不调用全局 `chdir`；重建后安全失效。
- 后台立即返回 task/log/status，正常 run 结束后继续；取消 run、删除 thread、Core 退出会终止归属进程树。
- Windows 回退顺序 Git Bash -> pwsh -> powershell -> cmd，并报告实际 shell。
- 不存在 restricted/supervised/staging/broker-receipt 分支；raw delete 不伪造 Trash。

### 2.4 Glob / Grep

- 使用 run snapshot 中固定的真实 `rg`，通过 argv 启动，默认 hidden/no-ignore。
- `Glob` 结果由 Go 稳定排序，默认最多 100 条并报告 total/truncated。
- `Grep` 覆盖 pattern/path/glob/type/output mode/A/B/C/n/i/head/offset/multiline；无匹配是正常中性结果。
- `rg` 缺失返回 `needs_runtime`，不得使用弱化 Go 搜索替代。

### 2.5 项目文件夹组的模型可见性

- provider 请求的 system prompt 里能读到当前项目名、整组项目文件夹和主文件夹标注；只出现在宿主侧 `runtime_snapshot` 不算通过。
- 单文件夹项目不重复列出文件夹组；零文件夹项目说明自己运行在 session 目录里，不把内部路径列成用户选的文件夹。
- 多文件夹项目里问「其他文件夹呢」，模型据清单回答，不靠 `..` 向上级目录试探。
- 项目改名后同一 thread 的下一次请求就用新名字，不需要重启 Desktop。

### 2.6 WebSearch

- Exa 覆盖 JSON/SSE 成功、无结果、malformed、JSON-RPC error、限流、网络、超时、响应上限和取消；Tavily 覆盖 keyless header、标准结果解析、原生域名参数、限流、malformed 和响应上限。
- `allowed_domains` 与 `blocked_domains` 不能同时非空；域名规范化同时作用于 provider query 和返回 URL 二次过滤。
- 默认最多十条；当前 Exa 与 Tavily 产品路径都不接收 API key，搜索配置只保存渠道开关。
- 真实 Desktop 分别验证每张渠道卡片的连接测试、免 key Exa、免 key Tavily、Exa 失败后 Tavily fallback、Exa 成功时不调用 Tavily、全部关闭和开关触发 Core 重启。

## 3. 模型媒体与重放

- `supportsVision`、`supportsNativePDF` 进入 Desktop profile、cache key、Core、父/子 Agent、Read 和 provider；存量 native PDF 默认 false。
- Anthropic 复合 `tool_result`；OpenAI-compatible 先发送同批全部 tool-role 结果，再发关联 call ID 的多模态 user message。
- Base64 只在内存；tool result blob 写入 `sessions/<thread>/tool-results/<tool-call>/`，Journal/compaction 只保留 storage key。
- 重启水合、thread 删除清理、blob 缺失 `tool_media_blob_missing` warning、旧新工具卡片回放和 token estimation 都必须回归。

### 3.1 Agent Plan 图片组图

- `image_generate` schema 必须只暴露创作参数，不暴露模型、账户或凭据；`mode=single|group` 与 `max_images=1..15` 由同一 run snapshot 用于模型和执行校验。
- single 映射官方 `disabled` 且不发送组图 options；group 映射 `auto` 与 `max_images`，非法 mode、缺少上限、越界或 single 携带上限都不得发起 Provider 请求。
- 非流式响应返回多少张，工具就逐张下载、签名校验、原子保存并发布多少个 ready Artifact；不得把上限写成精确返回数量。任一项失败不得发布伪成功批次。
- `src/tools/media_generate/media_generate_test.go` 覆盖单图、组图字段、1/15 边界、非法组合零请求、全部结果下载与 Artifact 数量。

## 4. 保留安全合同

- `PermissionDecision` 只有 behavior/reason/error code；AG-UI/Renderer 不再依赖 approval title/description/risk/affected-path/patch metadata。
- 普通工具零审批；`ask_user` 是唯一任务输入 gate；Guardian 继续只读且不能继承写入/open-world profile。
- `trash_file` 继续覆盖 macOS Trash、Windows Recycle Bin adapter 和 Linux fail-closed；raw Bash 删除不获得恢复事实。
- `dependency_install` 继续验证 plan/environment/executable，使用最小环境、full sandbox、private staging、nonzero/timeout/cancel discard、post-probe 和 Trash commit。
- `git_remote` 继续验证 HTTPS/DNS/proxy/credential isolation/pinned Git helper，clone 只发布 destination，replace preimage 可恢复。
- `memory` 只通过 host-owned service 访问 user/project Markdown 根，校验 source identity、revision、scope、敏感内容和重复主题；mutation 成功回执不返回主题正文，Dream 不绕过该 service。
- MCP Artifact bridge 继续覆盖 metadata invalid 仅停用 bridge、base64/hash/size/MIME/container/TaskScope、exact delta、并发 guard、Trash replacement 和取消清理。
- `WorkspaceExecutionBroker` 仅属于上述 dependency/git/MCP 路径；不能重新接入 Bash。

## 5. 真实 Awaken Desktop

从根 README 正式入口执行 `close:desktop -> open:desktop`，确认 `/health` 后，在隔离 workspace 完成：

1. 工具目录只显示七个模型基础工具及保留/动态工具；普通调用无审批卡片。
2. Bash thread cwd、前台失败/timeout、后台 task/log/status 和取消清理。
3. Read 文本、图片、原生 PDF 与 Poppler PDF；真实视觉模型能描述工具读取的图片。
4. Edit/Write 的预读、成功修改、外部改动拒绝；Glob/Grep 的 hidden/no-ignore 与无匹配。
5. WebSearch 真实 provider 的域过滤、来源和一个结构化错误。
6. 使用 Bash/Write/Skill 生成 Word、Excel、PPT、PDF、Markdown，再逐个 `artifact_publish`，确认终态卡片可点击。
7. 完整重启后确认新旧工具卡片、媒体结果和旧 typed Artifact 记录不崩溃，并在真实 Workbench 留存证据。

真实视觉模型、有效 WebSearch provider 或 Desktop 操作任一不可用时，必须列为阻塞，不能声明全量完成。Windows 本轮若只有自动化/cross-build，只能声明该层通过。
