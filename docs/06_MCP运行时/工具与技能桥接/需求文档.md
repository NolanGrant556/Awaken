# 工具与技能桥接 · 需求文档

MCP 工具进入统一工具目录，prompt 和 resource 可以按支持的方式提供技能内容；连接、权限和交付物仍由各自的宿主机制管理。

MCP 工具沿用提供方的输入格式。只读性质需要明确、有效的声明，不能从名称或描述猜测；声明也不等于宿主已观察全部副作用。普通 MCP 调用不自动获得工作区隔离、废纸篓恢复或消息审批。

工具可能提供文件交付物；只有选择了宿主文件桥接的调用才进入受控发布。适配器不自动重发请求。

代码、接口和验证方法见[实现方案](实现方案.md)。

## 动态技能正文

MCP prompt 技能使用服务器实际返回的指令和本次参数，资源技能读取原始资源 URI。目录摘要不等于指令正文。当前桥接支持文本；不支持的媒体、空正文或过大正文须明确失败，不能只执行摘要或无内容成功。
