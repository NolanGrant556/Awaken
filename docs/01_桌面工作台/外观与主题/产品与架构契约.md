# Desktop外观与主题产品及架构契约

## 1. 权威范围

本文唯一拥有 Desktop主题偏好、存储、系统跟随、token边界和真实验收。Design System各token的具体值由其自身文档/源码拥有。

## 2. 当前支持

Settings > 外观提供：

- 跟随系统 `system`；
- 浅色 `light`；
- 黑色 `dark`。

未有偏好时默认 `light`。选择即时应用到主窗口；保存失败时UI回滚到前一偏好并显示错误。

## 3. 偏好与生效主题

存储偏好类型：

```ts
type AwakenThemePreference = "system" | "light" | "dark";
type AwakenTheme = "light" | "dark";
```

`system` 不是CSS主题值：

- Electron Main用 `nativeTheme.shouldUseDarkColors` 决定窗口backgroundColor；
- renderer用 `matchMedia('(prefers-color-scheme: dark)')` 决定DOM实际主题；
- 系统外观改变时，只有preference=system跟随更新。

## 4. 存储与启动

最终来源是Electron Main `DesktopPreferencesStore`：

```text
<userData>/config/desktop-preferences.json
{ "version": 1, "theme": "light|dark|system" }
```

无文件、无效JSON或未知值归一到light。Renderer另写localStorage镜像 `awaken:appearance:theme`，用于React初始状态和减少启动闪烁；main加载成功后覆盖镜像状态。镜像不是最终来源。

DOM应用：

```text
html[data-aw-theme="light|dark"]
html[data-aw-theme-preference="system|light|dark"]
style.colorScheme = light|dark
```

主进程保存后只同步更新主窗口背景，避免主窗口在透明/加载阶段露出错误底色；独立透明浮窗（如宠物窗口）保留自身透明背景，不随主题更新。

## 5. 样式ownership

- 颜色、surface、text、border、status、composer等通用语义优先在 `Awaken Design System/src/tokens/` 定义。
- Desktop renderer只做场景级覆写，不在业务组件按主题分支渲染不同DOM。
- 新颜色先寻找/补充语义token，禁止到处新增hex/rgb magic value。
- brand wordmark使用 `--aw-brand-wordmark-filter`。
- 顶部chrome使用 `--aw-surface-chrome`，dark时不得比主工作区明显更浅。

## 6. Composer主题边界

Dock composer依靠RunStage真实底部留白避让内容；不得用全宽大面积渐变或 `backdrop-filter` 遮住历史。

允许随composer宽度收缩的局部 `--aw-composer-halo` 羽化；禁止重新引入白/灰/黑的全宽矩形雾化区。composer层级使用：

- `--aw-composer-surface`；
- `--aw-composer-border`；
- `--aw-composer-shadow`；
- `--aw-composer-shadow-focus`。

该边界同时受中间区域架构/验收约束。

## 7. 当前不支持

- 自定义主题/色板；
- 除light/dark外的主题；
- workspace级主题；
- 账号云同步；
- 业务组件级独立主题结构；
- 自动高对比模式开关（依赖系统/现有token表现）。

## 8. 异常与恢复

- 主偏好读取失败：保留localStorage镜像或默认light；
- 保存失败：renderer回滚并提示；
- 未知存储值：归一light；
- system matchMedia不可用：renderer fallback light；
- Main与renderer短暂不同步：最终以main返回偏好收敛。

## 9. 测试与真实验收

自动化：

- `apps/desktop/src/main/desktop-preferences-store.test.ts`：默认、dark、system、未知值。
- `apps/desktop/src/renderer/settings/DesktopSettingsDialog.test.ts`：三选项、selected状态。
- `npm run typecheck:desktop`、`npm run typecheck:ui`、`npm run smoke:ui`。

真实Desktop：

1. 三种偏好逐一切换并确认即时生效；
2. 重启后保持；
3. system下切换OS外观；
4. 检查主工作台、Settings、popover、center/dock composer、按钮、附件；
5. dark下wordmark白色、chrome无浅色横带、附件删除按钮可辨识；
6. light/dark均无全宽矩形composer雾化。
