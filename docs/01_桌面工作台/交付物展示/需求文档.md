# 交付物展示 · 需求文档

运行结束后，用户从交付物卡片打开或定位生成文件。卡片只展示已有的发布结果，文件是否可打开必须由宿主重新检查。

代码、接口和验证方法见[实现方案](实现方案.md)。

## 打开和定位

交付物显示在该轮最终回答之后。单击文档、图片或视频卡片，在右侧文件工作区打开临时标签；同一交付物不重复建标签。更多菜单提供系统应用打开和文件管理器定位。

打开卡片造成右侧栏展开或从文件覆盖态返回会话时，保留该会话的阅读位置，不滚回第一条消息。阅读位置与暂停跟随规则见[工作台布局与运行展示](../工作台布局与运行展示/需求文档.md)。

临时 Markdown 标签保持只读。文件缺失、引用失效或系统没有默认应用时，应显示明确错误，不自动选择其他应用或猜测文件路径。

## 支持格式

映射为 word、markdown、excel、pdf、powerpoint、image、video。扩展名比较不区分大小写；没有扩展名或未知扩展名不投影。

## 当前不支持

- 未终态 run直接打开；
- preview/support卡片提升为最终交付物；
- 浏览器内嵌 Office/PDF编辑器；
- 把媒体绝对路径或 `file://` 暴露给预览组件；
- renderer直接打开任意路径；
- 无系统默认应用时自动选择第三方应用；
- 不在支持扩展名列表的任意文件。
- 通过 magic bytes、MIME 或内容解析确认文件真实格式；
- 编辑或覆盖写回从交付卡打开的临时 Artifact Markdown；只有从当前项目文件树打开且 Main 重新通过项目边界校验的 Markdown 才可编辑保存。
