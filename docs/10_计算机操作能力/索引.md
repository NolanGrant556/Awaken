# 计算机操作能力域索引

本目录拥有 Awaken Computer Use 的当前边界和已确认目标设计。索引只负责读档路由，不复制契约内容。

## 事实状态

- **当前支持**：Awaken 开发构建已具备端到端原生 Computer Use：生产工具注册与 readiness 门控、CUA Host v2 checked-perform/quiesce、Runtime review/verify/session 控制、AG-UI/Desktop 控制面、固定媒体策略和运行时自动准备均已接通；正式发布仍受打包签名与真实 Desktop 准入证据约束。唯一权威见 [当前支持边界](./当前支持边界.md)。
- **已确认目标**：首个本机 Computer Driver 采用开源 [trycua/cua](https://github.com/trycua/cua)，由 Awaken Runtime、安全策略和 Desktop 控制面统一托管；CUA Host 与 Node runtime 的生产打包签名、正式 Desktop 任务验收仍是进入完全产品能力的缺口。
- **暂不承诺**：CUA Sandbox/Lume、远程桌面池、多租户 data plane 和无人值守高风险操作不属于首版范围。

## 契约 owner 分层

相邻契约按下列层级组合，不互相复制：

- 产品文档拥有风险类别和用户可见的 review/handoff/takeover 行为；
- 状态文档拥有实体、状态转换、route schema 和 wire payload；
- 安全文档拥有调用者鉴权、action digest 绑定、lease/fence、fail-closed 和恢复不变量；
- 架构文档只指定实现这些契约的代码模块与依赖方向；
- 测试文档拥有证明上述契约成立的准入证据。

改变某层语义时必须检查其相邻层，但不得在另一文档另起一套定义。
