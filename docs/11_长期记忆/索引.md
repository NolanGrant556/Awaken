# 11 长期记忆

本域拥有跨 thread 长期记忆、Markdown 存储、相关性召回、受控写入、Dream 整理、Settings 管理和记忆事件语义。Memory recall 与 Dream 的模型选择、purpose/预算和用量账本口径由 [02 提示词缓存、上下文用量与成本治理](../02_主智能体闭环/提示词缓存与成本治理.md) 统一约束。

当前支持 user/project Markdown topic、`MEMORY.md` 重建、受控 `memory` 工具、host 来源 identity、revision/敏感内容门禁、默认主动记忆、复用主模型 profile 的非阻塞相关性召回、无正文 SemanticJournal/AG-UI receipt、Memory HTTP，以及 Settings 四开关、按用户/项目集合查看 Markdown、删除和手动 Dream。Auto Dream 已接入持久化的 5 run/20 mutation、24 小时、Desktop 空闲 5 分钟和 active-run gate。Dream task/report 支持重启恢复，scope lock 支持 heartbeat，维护批次使用跨进程 staged transaction 与 crash rollback；Workbench 支持 Memory/Dream 紧凑回执及 Dream 重启重放。Settings 不提供人工创建、编辑、搜索、筛选或 supersede；Core 的受控 search 与召回能力不受影响。原生 Subagent 已有只读运行时，但 child 尚未继承父 `MemoryRecallSnapshot`，该项仍是强制后置缺口。
