- [原生 Subagent 产品与架构契约](原生Subagent产品与架构契约.md)：当前已支持正式 `subagent` 工具、run-scoped `explore/plan/review/general`、`shared_readonly/shared/git_worktree`、每 run 8 个任务/4 并发、耐久终态自动进入 root 下一模型边界、status/wait/cancel/message、Memory snapshot 继承、orphan `interrupted`、耐久生命周期事件、HTTP 控制面，以及 Desktop 任务组和 Inspector。递归 spawn、隐式 fork、自动 merge 和真实 Desktop AC-SA 走查仍是明确缺口或本次未执行项。深度研究目标为 Core 宿主编排器（`src/researchruntime`），复用 journal-first host spawn 与只读角色，并为研究 child 额外移除 Memory 和动态 provider；不占用 `subagent` 工具名，见 [16 深度研究](../16_深度研究/索引.md)。**当前不支持**。
- [ACP 智能体协作设计与实施方案](ACP智能体协作设计与实施方案.md)：Awaken 作为 ACP Client 已落地（Phase 0–4）；`delegate_external_agent` 支持 list/status/start/message/cancel/close，runner 配置、会话管理、工具进度/权限事件已接入 AG-UI。Awaken 作为 ACP Agent 的 stdio transport、launcher lease、control routes、事件投影、模型 profile selector/default fallback 与 cancel/close 已实现；Desktop-owned 与 core-only 的真实 stdio prompt 已通过，第三方 client、headless 多进程验收与跨 Core 重启恢复仍未完成。
- [验收](验收.md)

跨 thread Markdown Memory、主模型 selector recall snapshot、compact 后预算复位、主动记忆指导、Auto Dream 调度和 Dream task 重启恢复已实现；原生 Subagent child 继承父已召回的 `MemoryRecallSnapshot` 子集，不自行扩大 user/project scope。原生 Subagent 的 parent/child identity、任务编排和 UI 合同见 [原生 Subagent 产品与架构契约](原生Subagent产品与架构契约.md)，Memory 当前事实进入 [11 长期记忆](../11_长期记忆/索引.md)，不能由 thread 历史或压缩摘要替代。

root Agent 当前可通过固定快照中的 `archived_history` 按 `thread_id` 只读查询归档会话；归档内容不自动进入上下文、不能替代 Memory，也不向 Subagent child 继承。归档产品与数据边界见 [会话归档设计契约](../01_桌面工作台/左侧栏/会话归档设计契约.md)。
