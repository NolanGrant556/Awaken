## 1. 实现路径

| 组件 | 路径 |
|------|------|
| Canonical record | `src/agentcore/semantic_record.go` |
| Recorder 接口与持久化辅助 | `src/agentcore/semantic_journal.go` |
| 每 thread journal | `src/runtime/execution_journal.go` |
| v1 只读适配 | `src/runtime/legacy_transcript_adapter.go` |
| Thread 打开 / orphan 恢复 | `src/runtime/journal_store.go` |
| AG-UI projector | `src/protocol/agui/semantic_projector.go` |

新 thread 写入 `schema_version=2` JSONL（同路径 `thread_<id>.jsonl`）。既有 v1 文件由 `LegacyTranscriptAdapter` 投影为 SemanticRecord，不原地重写。

## 2. Canonical record

唯一 canonical 类型为 `agentcore.SemanticRecord`，`schema_version=2`。

稳定 kind：

- thread
- run_started
- user_message
- assistant_message
- tool_call
- tool_result
- artifact
- file_change
- turn_diff
- permission_decision
- skill_activated
- resource_receipt
- runtime_notice
- recovery_decision
- turn_boundary
- run_terminal
- persistence_warning

每条记录至少包含：`schema_version`、`record_id`、`seq`、`session_id`、`thread_id`、`run_id`、`turn_id`、`parent_id`、`kind`、`timestamp`、`payload`。

## 3. 耐久与临时边界

必须写入：

- 用户消息与每次完整可见 assistant message
- ToolCall 最终参数、skill_id、call_id、宿主 activity
- ToolResult 完整 ToolOutcome
- Artifact、planned/applied file_change、最终 TurnDiff（单条 unified diff 上限 50,000 字符，超出 truncated=true）
- Skill 激活、resource receipt、runtime/auth/recovery、turn/run 终态

默认不写入：

- stdout/stderr 每个 delta
- reasoning / TextDelta
- spinner、百分比 tick
- tool args streaming delta

## 4. 写入接口与顺序

- `agentcore.SemanticRecorder`：`Append` / `AppendBatch` / `Flush`，全部返回 error。
- `runtime.ExecutionJournal` 实现该接口；`EventSink.Emit` 只负责成功落盘后的直播广播。
- 正式 `StartRun` 缺少 recorder 时返回 `persistence_unavailable`。
- 顺序：先 SemanticRecorder 成功，再 EventSink；`tool_call` 必须在真实工具执行前写入成功。
- `tool_result` 与 artifacts 同批；`turn_diff` 在 `turn_boundary` 前。
- terminal 后 Flush 并 `file.Sync`。
- AppendBatch / terminal Flush 固定重试：50ms、200ms，最多 3 次实际尝试。

## 5. 故障语义

- `run_started` / `user_message` / `tool_call` 写入失败：立即取消，真实工具不得执行。
- 副作用后的 `tool_result` / artifact / terminal 写入失败：`persistence_degraded`，保留 pending，用户可见警告。
- terminal flush 最终失败：终态 `persistence_error`。
- 禁止忽略 Append / Flush error；`FlushTranscripts` 返回 error。

## 6. 重放

- 服务端用 `SemanticProjector`（及等价 AgentEvent 投影）将 SemanticRecord 转为 AG-UI events。
- live 与 transcript API 共用同一投影形状；Desktop `actionsForThreadTranscript` 只按序 dispatch，不得猜测丢失的 ToolCall/ToolResult。
- 仅在 v1 缺最终文本事件时保留 assistant result compatibility fallback。
- live/replay 等价测试只允许忽略接收时间、流式 delta 游标、纯动画状态。
- orphan run：未配对 `tool_call` 追加 synthetic interrupted outcome（`ErrorCode=process_restarted_outcome_unknown`），再追加 `run_terminal(status=interrupted, reason=process_restarted)`；不得自动重执行。
