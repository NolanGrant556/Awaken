# 本地服务管理 · 需求文档

Desktop 负责本地 Core 的启动、连接、监督和关闭。用户从正式 Desktop 入口使用 Awaken，不需要自行维护另一个 Core。

## 启动和连接

打开应用后，Desktop 启动 Core，或校验身份后接管已有的受管 Core。启动中不能提前发送任务；失败时显示原因和重启提示，不能显示成任务仍在运行。

应用自动处理本地端口和服务地址。Windows 的代理变化监听进程由 Desktop 一并管理，不是第二个 Core。

## 退出和恢复

退出时按所属关系关闭进程；不能误杀其他应用、不同身份或不同数据目录的 Core。断线后恢复已有记录，不自动重放已发生副作用的操作。

进程归属、身份校验、状态变化和异常恢复见[实现方案](实现方案.md)。
