# 04 工具、权限与安全执行

本域拥有 Tool Catalog、provider/capability/dependency、每 run 可用性快照、TaskScope、执行决策、Outcome、当前登录用户 Shell、可选 restricted/staging broker，以及 typed 文件/Artifact。它不拥有通用逐工具审批或消息发送审核门，也不把 typed provider 的边界声称为 raw Shell 的全局边界。

- [工具定义与暴露](工具定义与暴露.md)：目录、provider manifest、环境与工具快照。
- [工具决策、Outcome 与失败监督](工具决策、Outcome与失败监督.md)：默认自动执行、专用 gate、结构化失败与恢复。
- [TaskScope 与路径安全](TaskScope与路径安全.md)：读写根、附件和敏感路径。
- [Shell 本机执行面](Shell本机执行面.md)：默认当前登录用户 direct provider、真实环境继承、Skill 初始化、未观测副作用，以及可选 restricted/staged broker。
- [Typed 文件工具与可恢复删除](Typed文件工具与可恢复删除.md)：文件读写、patch 与 Trash。
- [Artifact 与演示文稿工具契约](Artifact与演示文稿工具契约.md)：typed artifact provider 的当前能力与非独占边界。
- [验收](验收.md)：自动化、平台矩阵和真实 Desktop 验收。
