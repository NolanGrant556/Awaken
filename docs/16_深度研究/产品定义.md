# 深度研究 · 产品定义

> 事实层级：**已确认但尚未实现的设计约束**。当前 Desktop **不支持**深度研究入口。实现后，本文件升为当前支持权威；入口、能力边界与验收不得与 [深度研究设计契约](深度研究设计契约.md) 冲突。

## 解决什么问题

用户需要一份**可核验**的研究报告：多来源对照、主张分级（已核实 / 部分核实 / 未核实）、每条关键结论可回溯到网页或当前工作区文件。这与单轮对话检索、只读 explore 子代理、以及用户 Skill 脚本不是同一条产品能力。

## 用户入口（目标）

- Composer `/deep-research <问题>` 或 `/研究 <问题>`，`SlashAction.type = workflow`。
- 无参数时提示用法，不启动研究。
- 入口由 Desktop 绑定，**不是**用户 Skill，也不是 Core `subagent` 工具名。

## 当前不支持（实现完成前）

- 无 `/deep-research`、`/研究`、宿主研究进度或研究耐久证据。
- 无独立 WebFetch 工具；现有 WebSearch 不能代替 URL 核验。
- 不把用户 Skill、explore 子代理或 AG-UI `update_plan` 单独使用称为深度研究。

## 目标支持

- 只读多源研究：公开网页 + **当前已打开工作区**；不远程 clone、不改仓库。
- 四阶段：规划 → 并行检索 → 核验 → 带引用报告。
- 研究子代理无 Bash / Edit / Write，也不继承 Memory、MCP 或 Connector 工具。耐久事实进入当前 Awaken data root 下的研究存储，不进项目树；最终 Markdown 由宿主经既有 typed `Write` + `artifact_publish` 链发布。
- 输出：Markdown 报告（主张分级 + 确定性 `[Sn]` 引用）+ Workbench 进度；公开网页引用可安全打开，工作区引用使用精确相对路径与行号。来源不可复验时降级为部分核实，不伪造来源。

## 明确不做（v1）

远程 git clone、跨 run 自动续研、Memory/MCP/Connector 取材、付费库、自动开 PR、用户可改的研究 Skill、把 Bash 当网页抓取。

## 实现与验收

模块边界、耐久存储、预算和验收项见 [深度研究设计契约](深度研究设计契约.md)。未满足该文档 AC-DR-01～09 前，不得把本能力写成当前支持。
