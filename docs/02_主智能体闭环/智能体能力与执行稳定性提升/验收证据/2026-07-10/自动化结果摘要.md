### 新增关键回归

- live、active transcript 与重启 transcript 对 ToolCall、ToolResult、Artifact、Recovery、terminal 的字段和顺序等价。
- `streamCursor` 与 `semanticSeq` 分离；新 `after_cursor` 和旧 `after_seq` 均可续接，无重无漏。
- terminal 只在 `Flush` 成功后直播；fsync 失败不会泄漏假成功 terminal，最终 `persistence_error` last-wins。
- StartRun 在创建 journal 前完成 thread-store prepare；rollback 不遗留 ghost/busy thread；user-message 持久化 fail-stop。
- Skill 每次调用使用独立 activation context；required resource/runtime fail-closed；多 Skill 激活原子化；receipt 耐久。
- raw `apply_patch` 普通 provider 默认隐藏；typed error 进入 ToolRuntime/Supervisor，exact/class budget 与 recovery 可因果复原。
- Artifact 只在工具成功后发出；direct 与 shell→typed transform 两条路径的业务失败都不会生成假 `ArtifactUpdated`。结构化 `diagnostic` 已从 ExecutionOutcome 贯通 SemanticRecord、AG-UI、Desktop reducer/narrative 与 durable replay。
- RunService 的 transcript 收尾只投影 legacy conversation/event，不再二次 Flush canonical recorder；canonical terminal 的 Append/Flush 失败由 Runner fail-stop 为 `persistence_error`。
- prepare-only 的 `AWAKEN_PYTHON` / `AWAKEN_SOFFICE` / `AWAKEN_POPPLER_BIN` 不再影响 Go 执行解析，正式 Artifact 工具只使用 managed active revision。
- PPT comparison 支持 1–3 列，9 类 layout 的已声明 body/subtitle 均被消费；未知/不兼容字段返回带 JSON path 的结构化 `validation_error`，不静默忽略。
- PPT warning/create/edit 失败不发布 final 或假 Artifact；原地编辑失败保持原 SHA；成功路径原子替换并发布最终 preview 路径与正确权限。已有 preview 目录若含无关文件、symlink 或特殊节点会在 rename 前 fail-closed，保留 deck、preview 和用户文件原状。
- 中文/emoji 标题与 output excerpt 按 rune 截断，不切坏 UTF-8。
