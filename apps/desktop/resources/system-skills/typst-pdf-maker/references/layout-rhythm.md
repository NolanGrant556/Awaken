# Typst 长文档节奏

仅在 Skill 自带报告基底、用户明确要求整体重排，或诊断本 Skill 生成的正文节奏时读取本文。出版模板、简历、发票、卡片、速查表和第三方包内部样式由其自身拥有，不套用本文。

## 默认正文

- A4 页边距：上下约 2.4 cm，左右约 2.1 cm；
- 正文字号：10.5–11 pt；
- `par.leading`：0.68–0.78 em；
- 段后距：0.65–0.85 em；
- 中文连续正文可用 2 em 首行缩进；Markdown 转换默认不缩进；
- 一级标题上方约 1.2 em、下方约 0.7 em；二级标题略收紧。

## 调整顺序

1. 先满足用户、学校、期刊或企业模板的硬性要求；
2. 再检查全局模板的页面、字体和标题规则；
3. 再检查 Universe 包是否拥有局部组件间距；
4. 只有仍属于 Agent 自己的正文区域才调整 Skill 主题；
5. 每次只改变一个节奏变量，重编一页密集正文检查结果。

## 常见错误

- 不通过缩小全文字号解决单个宽表格；
- 不同时叠加段后距和空行制造双倍间隔；
- 不在第三方模板外再次设置全局 `page` 或 `heading`；
- 不用绝对定位修补正常正文流；
- 标题不得孤立在页尾，图表不得与首次讨论相距过远。

## 复核

选择至少一页包含三个以上段落、一个二级标题和一个图表或代码块的密集页，检查：段落可区分但不松散、标题归属明确、页尾不过度留白、跨页内容没有遮挡或断裂。
