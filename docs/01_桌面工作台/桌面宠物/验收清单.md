# 桌面宠物功能验收清单

本清单依据 `实现方案.md` §18-19 整理，用于功能交付前的逐项核对。

## 工程检查

- [x] `npm run typecheck:desktop` 通过
- [x] `npm run build:desktop` 通过
- [x] `npm --workspace @awaken/desktop test` 通过
- [x] `git diff --check` 无格式错误

## 数据层与导入

- [x] Codex 合法自定义包无需转换即可导入
- [x] 启动扫描导入 `${CODEX_HOME:-$HOME/.codex}/pets/*/pet.json` 下全部合法包
- [x] 导入后删除 Codex 目录，Awaken 副本仍可使用
- [x] Codex 内置宠物不会被导入、下载或显示
- [x] Codex 当前选择 `selected-avatar-id` 不会被读取或同步
- [x] 自动导入、手动刷新、Codex 侧切换均不改变 Awaken 当前选择
- [x] 只有 Settings > Pets 中明确选择的宠物能驱动浮窗
- [x] manifest 非法、图片尺寸错误、路径逃逸等损坏包被隔离并报告，不阻塞其他包
- [x] 多个文件夹声明同一 id 时按规范路径排序导入第一个，其余报告冲突

## 浮窗与动画

- [x] 独立透明浮窗：`frameless`、`transparent`、`alwaysOnTop`、`skipTaskbar`
- [x] 浮窗透明空白区域不阻挡桌面点击
- [x] 宠物主体与通知托盘是命中区域，其余区域保持穿透
- [x] 九种动画状态与 Codex 契约一致：`idle`、`running-right`、`running-left`、`waving`、`jumping`、`failed`、`waiting`、`running`、`review`
- [x] `idle` 无限循环且帧时长按 6 倍放慢
- [x] 非 `idle` 状态播放 3 轮后回到 `idle`
- [x] 状态切换立即切到第一帧，不残留旧 timer
- [x] hover 触发 `jumping`，离开后恢复业务态
- [x] 左右拖拽 delta >= 4px 触发对应方向动画，松手恢复业务态
- [x] 首次 Wake 触发 `waving` 和 8 秒欢迎通知；同一只宠物不重复欢迎
- [x] 首次 Wake 时若已有 waiting 业务通知，waiting 压过 waving
- [ ] 系统 `prefers-reduced-motion` 开启时每个状态只显示静态首帧（代码已接入 `matchMedia`，需真实环境验证）

## 运行状态映射

- [x] 主动提问等待回答 -> `waiting`
- [x] 命令/文件/权限/MCP elicitation/实施计划等待 -> `waiting`
- [x] run `error` 或云任务 `cancelled` -> `failed`
- [x] run `running` 或 `cancelling` -> `running`
- [x] run 完成且未读 -> `review`
- [x] run 完成且已打开对应 thread/turn -> `idle`
- [x] 无活跃任务 -> `idle`
- [x] 多会话状态优先级：`waiting > failed > review > running > idle`

## 通知托盘

- [x] 最小态展示最高优先级通知
- [x] 展开态按优先级 + `updatedAtMs` 稳定排序
- [x] 通知过期时间：`running` 3 分钟、`failed` 1 小时、`waiting` 24 小时、`review` 7 天
- [x] 点击普通通知聚焦主窗口并导航到对应 thread
- [x] waiting 通知支持回答问题、允许/拒绝命令/文件/权限/MCP、开始实施 plan
- [x] running 通知在支持时提供 Stop
- [x] 单条通知可关闭；关闭后同一 turn 不重复出现
- [x] 托盘展开/收起不破坏宠物拖拽和透明穿透

## 设置页

- [x] Settings 对话框包含 Models / Pets 一级 Tab
- [x] Tab 具备 `role="tablist"`、`role="tab"`、`aria-selected` 和方向键切换
- [x] Pets Tab 显示当前宠物预览
- [x] 列表显示已导入 Codex 自定义宠物，按 `displayName` 稳定排序
- [x] 列表不显示 Codex 内置宠物
- [x] 单选选择控件；只有被选中的宠物能驱动浮窗
- [x] 选择某只宠物只更新 `selectedPetId`，若浮窗已打开则原位热切换
- [x] Wake Pet 只打开当前选择；未选择时禁用并提示
- [x] Tuck Away Pet 只关闭浮窗，不清空选择
- [x] 刷新 Codex 宠物只更新列表，不改变选择、不自动 Wake
- [x] 自动导入 Codex 宠物开关可用
- [x] 打开 Awaken 宠物目录、打开 Codex 宠物目录按钮可用
- [x] 导入错误列表可见

## 拖拽、缩放与定位

- [x] 宠物主体可拖拽
- [x] 4px 内视为点击，超过 4px 视为拖拽
- [x] 点击宠物唤起主窗口
- [x] 宠物宽度缩放范围 80px ~ 224px，默认 112px
- [x] 缩放只改变宠物宽度，不改变图集规格
- [x] 多显示器间拖拽后位置可恢复
- [x] 显示器移除后按分辨率和最近 work area 匹配恢复
- [x] 窗口超出屏幕后自动恢复到可见区域
- [x] 重启后位置、尺寸、选择、开关状态恢复

## 安全边界

- [x] 不读取宠物目录外资源
- [x] 不执行宠物包中的任何代码
- [x] 不允许 HTML、JS、SVG 成为 spritesheet
- [x] 不通过 renderer 暴露任意文件路径
- [x] 不修改 Codex 配置和文件
