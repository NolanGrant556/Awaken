# Office 后台渲染：架构与打包契约

## 运行时所有权

Awaken 使用独立的 Headless LibreOffice runtime；不得修改或复用用户正在使用的 LibreOffice/WPS GUI。macOS 专用 bundle 的真实 `LibreOffice.app` 设置 `LSBackgroundOnly=true`，不能同时设置 `LSUIElement`。

## Bundle 复制与签名

- bundle 内部相对符号链接必须原样保留。
- 断链或越出源 bundle 的链接必须拒绝。
- 修改 Info.plist、Mach-O 或资源后，必须按 nested code 由内到外重签。
- 开发构建允许 ad-hoc；发布构建只能在持有 Developer ID 的 CI 中从全新且签名有效的源 archive 构建、notarize 和 staple。
- CI 使用 `npm run package:runtime:archive` 输出当前平台 managed runtime 的 archive 及 SHA-256 manifest。macOS archive 额外保留 Developer ID、notarization、staple 和 designated requirement；Windows archive 只声明 archive integrity 及 `packaged-host` 信任边界，不能伪造 macOS 签名字段。
- 用户机器使用 `npm run install:runtime:archive -- --archive … --manifest …` 完成平台、架构、摘要、必需组件与内部 symlink 复验，再原子激活 immutable revision。macOS 额外执行 Developer ID requirement、notarization ticket 和 Gatekeeper；Windows 使用 PowerShell `Expand-Archive`，不执行 `codesign`、`xcrun`、`spctl` 或 `ditto`。
- Windows 普通 `npm run dist:desktop` 和 `dist:desktop:release` 都会在 Windows 构建机上把本次 `prepare:runtime` 产生的 Windows Python、Node、LibreOffice、Poppler、ffmpeg 和 helper packages 打进 Windows archive；绝不携带或重命名 macOS `LibreOffice.app`。PowerShell `Compress-Archive` 会忽略带 Hidden 属性的条目，因此打包器检测到 hidden runtime entry 时直接失败，不能静默生成残缺 archive。
- Windows archive 的 SHA-256 保证安装资源与 manifest 一致；正式对外发布的来源可信度由包含它的 Awaken 安装包 Authenticode 签名承担。本地未签名 installer 只能用于本机测试，不能描述为已签名发布物。

PowerShell 目录压缩与解压行为以 [Microsoft Compress-Archive](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.archive/compress-archive) 和 [Microsoft Expand-Archive](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.archive/expand-archive) 为准。

## OfficeRenderWorker

所有 Office 转换都经过同一个进程级 worker：默认单并发、相同任务 singleflight、每 job 独立 `UserInstallation` 和 staging、输入复制到私有目录、仅传递最小环境变量、超时/取消时清理整个进程组、成功后原子发布输出。任何工具不得自行执行 `soffice`；通用 local-compute 层会明确拒绝该 backend。

Runtime resolver 只从 Awaken 所有的 `current.json/state.json` 解析 active revision；调用工具不能传入 LibreOffice 路径。签名、平台、架构、内部 symlink 和 state 摘要的 attestation 每个 revision 只执行一次，运行期权限检查只读缓存快照。
