# AwakenMemorySettings

Awaken 当前设置页的记忆管理视图。上方“记忆”是自动召回、主动记忆和 Auto Dream 的总开关；四项统一消费原子 `AwakenSwitch`，开启为绿色、关闭为灰色。Desktop 关闭总开关时会把三个子设置一并持久化为关闭，组件通过 `checked=false` 与 `disabled=true` 显示它们不可操作；重新开启总开关时三个子设置默认一并开启，之后仍可分别关闭。除总开关级联外，单个子开关保存时只禁用当前提交项，不改变其他开关或手动“更新记忆”入口；“更新记忆”不受 Auto Dream 控制，但在总开关关闭时禁用。下方管理区不显示额外总标题，也不使用互斥标签切换，而是纵向同时展示两个纯 UI 模块：上方“最近动态”不显示附加说明或独立的“最近一次整理”汇总卡片，直接使用动态列表和紧凑详情弹窗展示当前 Memory 更新时间快照与 Dream task/report；“更新记忆”与运行中的取消入口放在“最近更新与整理”列表标题栏。动态行只显示类型、标题和时间，不在行内重复描述或 Dream 统计；可见标题按 32 个字符截断并追加 `.....`，完整标题、描述和统计仍由点击后的详情弹窗展示。动态列表默认展示最新 6 条，每次“显示更多”增加 6 条，最多展示 18 条；到达当前可见上限后显示“收起”并恢复为 6 条，列表不创建内部滚动区。

下方“记忆库”首页只显示“用户记忆”和“项目记忆”两个集合入口，不显示搜索、筛选或主题记录。用户入口进入该范围的全部主题 Markdown 列表；项目入口直接使用原子 `AwakenFolder` 的 `compact` 尺寸展示至少含一条主题记忆的项目，按 Desktop 传入顺序从左到右排列并在空间不足时换行，再进入该项目的全部主题 Markdown 列表。项目名称保持单行省略，悬停标题保留完整名称。用户或项目浏览与其 Markdown 正文复用同一个持续挂载的大型只读弹窗，只替换标题、正文和操作区；关闭项目正文在原弹窗内恢复到项目文件夹选择，关闭用户正文恢复到用户主题列表，从最近动态打开的正文则回到记忆主页。集合入口使用 Desktop 已经加载的有界元数据生成主题数、项目数和最近更新时间；单一来源达到 20 条读取上限时，数量显示为“至少 20”，不把有界快照误写为完整总数。项目文件夹不制造空项目或不存在的记忆文件。

范围、项目、按需详情、revision 删除以及 Dream 启动/取消均通过 props/callbacks 投影；`activities` 与当前集合的 `memories` 是两份独立输入，打开记忆库集合不会由组件改写最近动态。全局动态聚合、Memory API、Dream authority、revision 与持久化由 Desktop/Core 拥有。全局动态和项目浏览中的项目 Memory 会随打开回调传递项目 identity，Design System 不读取项目 store。组件不提供创建、编辑、打开文件夹、搜索、筛选、supersede、revision 历史、删除审计或趋势统计。

“更新记忆”只调用既有 Dream callback，不改变维护机制或新增数据请求。记忆库、动态详情和正文详情弹窗沿用现有弹窗关闭行为。
