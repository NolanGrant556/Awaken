# 11 长期记忆

本域拥有跨 thread 长期记忆、Markdown 存储、相关性召回、受控写入、Dream 整理、Settings 管理和记忆事件语义。

当前支持 user/project Markdown topic、`MEMORY.md` 重建、受控 `memory` 工具、host 来源 identity、revision/敏感内容门禁、默认主动记忆、复用主模型 profile 的非阻塞相关性召回、无正文 SemanticJournal/AG-UI receipt、Memory HTTP，以及 Settings 四开关、查看/筛选/删除和手动 Dream。Auto Dream 已接入持久化的 5 run/20 mutation、24 小时、Desktop 空闲 5 分钟和 active-run gate。Settings 不提供人工创建、编辑或 supersede。当前仍不支持 Dream task/maintenance receipt 的重启恢复、child recall 继承和 Workbench receipt 展示。
