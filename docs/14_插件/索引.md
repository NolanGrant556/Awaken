# 14 插件

本域拥有 Agent Plugins 1.0.0、Codex、Claude Code、Cursor 四方言识别与安装，Store v2、digest/generation lease、组件 inventory/configuration、跨运行时 projection 和验收分层。Desktop 插件页交互由 [01 扩展管理](../01_桌面工作台/扩展管理/插件页产品与架构.md) 拥有；Skill、MCP、Hook、Rule instructions 与 Subagent 的执行语义仍由原域拥有。

- [产品与架构契约](产品与架构契约.md)：当前支持、当前缺口、尚未实现的设计约束、目录与 identity、HTTP 与 owner。

跨域事实不在本域重复定义：

- plugin 来源 Skill 的发现、优先级、预览与删除边界由 [08 技能](../08_技能/索引.md) 拥有；
- `plugin` MCP scope、合并顺序与 `PLUGIN_ROOT` / `PLUGIN_DATA` 由 [06 MCP 运行时](../06_MCP运行时/索引.md) 拥有；
- 连接器「用户安装」排除 `plugin__` server 由 [07 连接器](../07_连接器/索引.md) 拥有；
- `/v1/plugins*` route 清单由 [09 HTTP 与 SSE 接口契约](../09_AGUI与A2UI协议/HTTP与SSE接口契约.md) 拥有；
- Plugin Hook 的 `SourcePlugin`、handler、预算与回执由 [04 Hook 契约](../04_工具权限与审批/Hook产品与架构契约.md) 拥有；MCP tool 仍由动态 MCP provider 注册。
- Plugin Agent 的角色收窄、并发、取消、Journal 与 UI task truth 由 [02 原生 Subagent](../02_主智能体闭环/原生Subagent产品与架构契约.md) 拥有。
