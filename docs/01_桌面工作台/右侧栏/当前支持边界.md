# 右侧栏当前支持边界

## 1. 权威范围

本文唯一拥有 Awaken Desktop右侧 Inspector的当前产品状态、已有数据和未接线边界。中间叙事的数据投影见 [叙事投影与重放](../中间交互区域/叙事投影与重放.md)。

## 2. 当前用户行为

主 Workbench 保留右侧 rail、折叠按钮、拖拽/键盘 resize 和响应式自动折叠。普通展开态始终提供“文件”入口；当前 thread 存在原生 Subagent 记录时，同时出现带任务数 badge 的“子任务”入口：

```text
文件
子任务 3
```

当前没有审阅、终端、浏览器等其他入口。点击“文件”后进入项目文件工作区：

- 顶栏左侧出现“打开文件”标签和关闭按钮；本期不提供新增标签的 `+`；
- Inspector 临时扩展到文件工作区宽度，关闭文件标签后恢复进入前的用户宽度；
- 点击路径栏右上角的文件夹按钮可收起或展开完整文件列表；收起时左侧文件区域占满工作区，再次展开恢复原有文件夹组、筛选、目录展开和文件选择状态；
- 文件区域与文件列表之间的竖向分隔线支持左右拖拽调宽，文件列表首次展开默认使用 240px 最小宽度，可在 240–400px 内调整，文件区域至少保留 240px；普通拖拽到 240px 只停在最小宽度，短距离快速移动或中等力度不会收起，只有从最小宽度边界继续明显长距离、高速向右甩动才会收起文件列表；分隔线获得焦点后可用左右方向键按 12px 微调，收起再展开时保留收起前的宽度；
- 工作区左侧是文件内容区域，但本期只显示“打开文件”空态，不读取或渲染文件正文；
- 工作区右侧依次显示当前项目文件夹组选择器、文件名筛选框和目录树；
- 文件夹组选择器只切换**同一个当前项目**已绑定的文件夹，不切换项目 identity；主文件夹默认优先；选择器和下拉选项只展示文件夹组名称与选中状态，不展示本机物理路径；
- 目录树按需读取：打开文件工作区时读取根目录，展开目录时再读取该层；目录排在普通文件前；文件夹沿用左侧项目树的 `Folder` / `FolderOpen` 状态，展开时箭头旋转、文件夹轻动和新出现子项淡入，系统要求减少动态效果时关闭这些动画；
- 筛选只作用于本次已经加载的树节点，并保留命中节点的已加载祖先；它不是全盘文件搜索；
- 点击普通文件只记录当前选择并高亮，不在本期打开预览；已知扩展名分别显示 Word、Excel、PowerPoint、PDF、Markdown、代码、数据、图片、压缩包、音频、视频或文本图标，未知格式回退通用文件图标；目录符号链接显示为不可展开的文件项。

“当前项目”优先采用当前活动 thread 的稳定 `projectId`，没有活动 thread 时采用侧栏当前选择的项目；独立对话或未选项目显示选择项目空态。项目没有绑定文件夹时显示无文件夹空态，不回退到默认 workspace、进程 cwd 或用户主目录。

点击“子任务”后进入 Subagent Inspector：

- 顶部显示选中 task 的 agent type、description 和 canonical status；
- task switcher 按创建顺序列出当前 thread 已投影的任务，切换选择不改变 task runtime；
- 详情显示最近活动、结果 preview 或稳定错误码；
- 只有 `queued/running` task 显示取消入口；进入 `cancelling` 后按钮消失，取消通过 typed Main/preload bridge 调用 Core，Renderer 不直接改状态；
- 切换 thread 时清理旧 `selectedSubagentTaskId`，默认选中新 thread 的首个 task；
- 当前不支持向 child 追加消息、完整 transcript、token/cost 统计、跨重启 selection 或窄屏专用 sheet。

连接器和技能是独立功能页，不使用 Workbench Inspector。进入这两个页面时，Desktop 必须同时隐藏 Inspector、resize handle、分隔线和顶栏展开/收起按钮，不为右栏保留空白宽度。返回主 Workbench 后恢复用户原有的右栏宽度和折叠偏好，不因路由切换改写它们。

因此旧“Right Inspector Rail”切片中下列描述已经失效：

- 完整InspectorTabs；
- selected tool args/result面板；
- Changes patch/turn diff面板；
- Files详情；
- Browser disabled tab；
- approval detail selection。

## 3. 当前壳与布局

- `WorkbenchShell` 仍接收 `inspector` slot和 `inspectorCollapsed`。
- 默认宽度 300px，允许在配置的 min/max 范围内 resize；文件工作区打开时使用 720px 宽右栏，当前 resize 上限为 760px，关闭后恢复进入前宽度。
- 宽度和折叠状态写入renderer localStorage。
- resize handle支持pointer和键盘。
- 窄窗口媒体查询自动折叠；恢复宽度时回到自动折叠前状态。
- 顶栏按钮可手动折叠/展开。
- 上述壳与布局只在主 Workbench 渲染；连接器/技能页只渲染自身主内容。

折叠文件工作区只隐藏面板，不关闭文件标签；重新展开仍回到同一文件工作区。连接器/技能等独立功能页继续隐藏整个 Inspector。

## 4. 当前文件目录数据链路

Renderer 通过专用 `listProjectDirectory` bridge 请求一个目录层级。Electron Main 每次请求都会重新从 Core 获取当前 active projects，并依次验证：

1. `projectId` 当前仍存在且 active；
2. 请求的 `folderPath` 与该项目当前绑定的文件夹精确对应；
3. 相对目录不含绝对路径或 `..`；
4. lexical target 与 realpath target 都留在注册文件夹内；
5. 目录可读。

Main 只返回 `name`、项目文件夹相对路径和 `directory/file/symlink` 类型，不把绝对读取能力或任意文件读取 API 暴露给 Renderer。目录符号链接可以显示，但不能作为目录继续遍历；通过符号链接逃逸到项目外的请求 fail closed。此链路是项目文件浏览的专用只读边界，不改变 Agent `TaskScope` 对工具调用的语义。

## 5. 已有但未接线的数据

Desktop reducer/projector当前持有：

- `narrative.inspectorSelection` union；
- tool args、result、status、bounded command output和truncated flag；
- artifacts和role/status/path；
- patch/turn diff数据；
- `inspectorSummary.lastToolDecision`；
- context window摘要。

上述通用 tool/artifact 数据当前仍未接线，不等于右侧已经支持通用工具详情。Subagent Inspector 是独立的已实现入口，只消费 Subagent narrative task identity，不把通用 tool record 私接进右栏。

## 6. Owner

- 壳/slot：`Awaken Design System` 的 `AwakenWorkbenchShell`、`AwakenInspectorRail`。
- 折叠、宽度、顶部文件标签和当前项目选择：`apps/desktop/src/renderer/App.tsx`。
- 文件工作区 UI、文件夹组选择、筛选和懒加载树状态：`apps/desktop/src/renderer/ProjectFilesWorkspace.tsx`、`apps/desktop/src/renderer/projectFiles.ts`。
- project-scoped 目录读取与路径校验：`apps/desktop/src/main/project-files.ts`。
- typed IPC：`apps/desktop/src/shared/runtime.ts`、`apps/desktop/src/preload/index.ts`、`apps/desktop/src/renderer/runtime/client.ts`。
- 当前未接线的数据 owner：`apps/desktop/src/renderer/runtime/reducer.ts`、`apps/desktop/src/renderer/run-narrative/types.ts` 和 `apps/desktop/src/renderer/run-narrative/projector.ts`。
- Subagent group/Inspector 产品状态：`apps/desktop/src/renderer/App.tsx`、`run-narrative/projector.ts`；UI-only group：`Awaken Design System/src/components/AwakenSubagentGroup`；typed cancel bridge：Desktop shared/main/preload/runtime client。

## 7. 硬边界

- 右侧详情不得进入 `ExecutionFeed`。
- 新Inspector必须消费已有reducer identity，不从DOM或文本重新解析tool/artifact。
- Browser没有真实runtime前不得显示假页面。
- Terminal不得变成交互式shell或绕过tool/runtime策略。
- Changes不得把preview等同已执行diff。
- 右栏交互不得改变run streaming/replay state。
- 详情组件如进入Design System，仍需UI-only；runtime lookup留在Desktop。
- Renderer 传入的 `projectId`、folder path 和 relative path 不是授权事实；目录读取必须在 Main 按当前项目重验。
- 文件工作区不得从 label 或物理路径反推项目 identity；同一物理文件夹可以属于多个项目。
- 当前 bridge 只能列目录，不能演化成不受约束的任意 `readFile(path)`。

## 8. 当前不支持

- 通用 tool/artifact Inspector tabs 和 selection；
- 命令输出详情；
- patch/turn diff详情；
- 文件内容读取、预览、编辑和保存；
- 图片、Excel、Word、PDF、PPT、代码和 Markdown 的格式化预览；
- 多文件标签、文件标签 `+` 和文件标签跨重启恢复；
- 把文件预览扩展到中间 RunStage，或在会话标签与文件标签之间切换；
- 未展开目录的递归/全项目搜索；
- browser automation surface；
- approval恢复；
- Inspector状态跨thread持久化。
- Subagent message、完整 transcript、token/cost 统计、窄屏专用 sheet 和 selection 跨重启恢复。

## 9. 验收

- 真实 Desktop 点击顶部“文件”后，确认顶栏出现“打开文件”标签、Inspector 扩展、左侧为空预览、右侧为文件夹组/筛选/目录树；拖动中间分隔线并用方向键微调，确认文件列表只能在 240–400px 内变化；普通拖拽到 240px 不隐藏，短距离快速移动和中等力度也不隐藏，再从最小宽度明显长距离、高速向右甩动才平滑收起；连续点击路径栏文件夹按钮，确认文件列表整体收起与恢复，树状态和上次宽度均不丢失。
- 为同一项目绑定两个测试文件夹，确认默认选中主文件夹，下拉选项不显示本机物理路径，切换后只展示对应树；切换项目或 thread 后不串用上一项目目录。
- 展开两层目录并筛选已加载文件，确认目录按需读取、文件夹展开状态与子项动效可见、祖先保留；使用 Word、Excel、PowerPoint、PDF、Markdown、代码文件和未知扩展名确认图标映射与通用回退，普通文件可选择但不出现伪预览。
- 使用 traversal、未绑定文件夹和指向项目外的目录 symlink fixture，确认 Main 返回 typed deny，Renderer 不展示项目外内容。
- 关闭文件标签后确认回到顶部单一“文件”入口并恢复此前宽度；折叠/展开/resize 仍可用。
- 折叠和窗口缩窄不能遮挡中间composer。
- 从主 Workbench 切换到连接器和技能，确认右栏、分隔线、resize separator和顶栏按钮全部消失；返回后原宽度/折叠偏好不变。
- reducer测试只能证明数据存在，不作为右栏功能验收。
- 真实 Desktop 创建只读 Subagent，确认中心 group、任务 badge、task switcher、running/completed/result；再取消一个运行中 task，确认 cancelling/cancelled、按钮消失与稳定错误码。
- 新增文件内容预览或任何其他详情前，必须同步更新本文、相关测试，并提供真实 Desktop 截图/录屏。
