# 验收规范

## 1. 自动化

- Go `Event` JSON tags 与 mapper/projector golden；
- live/replay 对相同 SemanticRecord 生成同 frames/seq；
- tool snapshot/provider/readiness/dependency/side-effect 字段端到端；
- 五种 Skill event、activation/resource durable projection；
- mass review digest、message count、recipient expansion requested/resolved；
- unknown event 保留 raw type，不让 consumer 崩溃；
- MCP artifact 原始 base64 不进入 Outcome/journal/AG-UI；成功只投影 host-committed ArtifactDescriptor/change/receipt，hash/size/path/commit 失败无伪 artifact，且不得从基础容器验证推断视觉/语义 verified；
- Go/TS field parity，特别是 auth URL。

```bash
go test -count=1 ./src/protocol/agui ./src/agentcore ./src/runtime
npm --prefix apps/desktop test -- --run src/renderer/runtime/reducer.test.ts src/renderer/run-narrative/projector.test.ts
npm --prefix apps/desktop run typecheck
```

具体 Desktop test runner 参数以 package scripts 为准；若命令不匹配，记录实际替代命令。

## 2. Desktop 验收

真实 Awaken Desktop 中验证 live、断线重连、切换线程、重开、Skill inline/fork、provider failure、群发审核和 artifact 的顺序/字段一致。检查网络帧与 reducer 状态，不能只凭最终文案。
