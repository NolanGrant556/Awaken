# 模型 API key 文件存储复核清单

本清单只复核 [模型 API key 文件存储与恢复契约](架构与恢复契约.md) 和 [模型配置与调用](../模型配置与调用.md)，不建立第二套字段或状态定义。

## 代码与数据

- [ ] `ModelProfileStore` 只读写 `~/.awaken/config/models.json`，没有旧 profile importer。
- [ ] `AwakenEnvStore` 是模型 key 的唯一持久化 owner；代码不依赖 Electron `safeStorage`。
- [ ] 每个 profile 只映射一个合法的 `AWAKEN_API_KEY_<profileId>`，不能注入额外 assignment。
- [ ] OpenAI/Anthropic 管理密钥只映射固定 provider-scoped 变量，不参与推理、profile ready 或推理 revision；Google 不伪造管理凭据。
- [ ] Agent Plan 固定账户只映射独立的 `AWAKEN_AGENT_PLAN_API_KEY_<accountId>`，不会复制进 profile secret。
- [ ] `.env` 同目录临时写入、原子 rename，并最终为 `0600`。
- [ ] 损坏/不可读 `.env` fail closed，不作为空文件覆盖。
- [ ] 保存、删除、template 复制、测试连接、能力同步、余额和 start-run 都按 profile ID 读取同一 key store。
- [ ] profile 写失败恢复此前 key；删除失败同样恢复。
- [ ] Agent Plan account metadata 为 versioned/原子/`0600`；key 实际轮换递增 revision，写失败恢复旧 key，被 profile 或生成工具配置引用时拒绝删除。
- [ ] `agent-plan-media-tools.json` 只保存账户引用、capability、精确模型、enabled 和 revision，原子写入且为 `0600`，不复制 Agent Plan Key。
- [ ] Core 只有在媒体配置 enabled、model kind 与 Main catalog 一致且固定账户 Key 可读时注册工具；ProviderManifest、tool schema、Outcome 和 Artifact 都不含 Key。
- [ ] `models.json` 只保存 `keyLast4`，不保存完整 key、密文 envelope 或 token。
- [ ] `model-capabilities.json` 位于 `~/.awaken/cache/`，失败不阻断静态能力。

## 状态与泄密边界

- [ ] 当前 profile status 只使用 `ready|missing_key|disabled|unreadable`。
- [ ] `.env` 读取错误映射 `credential_unreadable + retry/reenter`；写入错误映射脱敏 `operation_failed`。
- [ ] provider 401/403/429、网络和余额错误不被标为本地 `.env` 故障。
- [ ] Renderer、日志、Desktop issue、journal、thread metadata、run snapshot 和 lifecycle snapshot 不含完整推理或管理 key；Renderer 只获得账户掩码、状态和 revision。
- [ ] UI 与文档明确 key 是本地明文文件，不宣称 Keychain/DPAPI/safeStorage 加密。
- [ ] `keyLast4` 只用于掩码，真实 `has_key` 来自 `.env` 读取。

## 自动化

- [ ] `.env` 特殊字符、引号、`export`、非 Awaken 变量和空文件 round-trip。
- [ ] 推理、管理与 Agent Plan 三个变量 namespace 互不覆盖；管理 key 轮换不改变推理 revision。
- [ ] 非法 profile ID、损坏行、权限错误、写错误均有 fail-closed 测试。
- [ ] 0600、唯一临时文件、并发 mutation 与临时文件清理有测试。
- [ ] profile create/update/delete/template 及 models 写失败 rollback 有测试。
- [ ] Agent Plan account save/rotate/delete、内置目录迁移、上游目录分类/404 降级与失败保留、主模型与媒体模型双向过滤、profile/媒体配置引用删除保护有测试。
- [ ] 图片/视频每 capability 最多一个配置、同值幂等、active-run 保存门禁、Core 条件注册和 Key 不泄漏有测试。
- [ ] 旧 `model-profiles.json` 存在时不会被读取或导入。
- [ ] 余额、能力同步和真实 run config 读取的是目标 profile 的 key。
- [ ] Desktop operation/client/composer/余额 UI 覆盖新状态且无旧 temporary/relaunch 文案。

## 真实 Desktop

- [ ] 按根 README 正式入口完整关闭并启动 Awaken。
- [ ] 使用专用测试 profile 保存 key，UI 只有操作成功后提示已保存。
- [ ] 检查 `~/.awaken/.env` mode 为 `0600`，不在证据中展示内容。
- [ ] 完整重启后 profile、default、enabled、能力、Agent Plan account revision/分类模型目录、图片/视频单配置和 key 可用状态保持。
- [ ] 测试连接、支持的余额查询和最小真实 prompt 均越过 key 层。
- [ ] 删除 profile 后对应变量消失，其他变量保持。
- [ ] Renderer、日志和 SemanticJournal 不含完整 key、Authorization 或原始 provider secret body。

未执行真实 Desktop 或未检查文件权限时，只能报告自动化部分通过，不能宣称本域全部验收完成。
