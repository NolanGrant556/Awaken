# AwakenSettingsProviderCard

设置页中的供应商连接入口。`AwakenSettingsProviderCard` 固定三列和统一高度，只展示官方产品 Logo、供应商名称与“配置”动作；连接状态和模型数量不进入入口卡片。入口卡片使用纯色表面和细边框，不使用渐变炫光、悬浮阴影或上浮位移，hover 与选中只通过边框和纯色表面反馈。官方 Logo 保留供应商品牌色；卡片右侧的“配置”文字与箭头统一使用主文字色，不继承供应商强调色。设置交互不得使用红色或粉色，避免与错误、危险状态混淆，因此 MiniMax 仅在 Logo 内保留官方红色；hover、焦点、选中状态，以及配置弹窗的头部、链接、输入焦点和连接测试继续使用统一交互强调色。`AwakenSettingsProviderModal` 提供居中弹窗、背景遮罩、关闭与焦点恢复，连接状态紧邻供应商名称右侧展示。弹窗使用紧凑品牌头、带稳定间距的表单区和单行底部操作栏；自然内容高度受窗口最大高度约束，超出时仅内部滚动。模型、密钥、测试、保存、重复模型提示和业务状态仍由 consumer 提供，动效遵守 `prefers-reduced-motion`。
