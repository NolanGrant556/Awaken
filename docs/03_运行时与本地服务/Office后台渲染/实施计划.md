# Office 后台渲染：实施计划

1. 修复 runtime bundle 复制器的符号链接语义和安全边界。
2. 为 staged macOS LibreOffice 写入 `LSBackgroundOnly`，增加开发/发布签名入口和严格校验。
3. 建立 `OfficeRenderWorker`，把 typed artifact render、document/spreadsheet 转换和旧 `.xls` 读取统一接入。
4. 把 `soffice --version` 等重复探测移到 revision attestation，运行期不再 force probe。
5. 发布前验证签名、公证、中文 Office 转换、连续任务、取消和无 Dock 激活。
