# 14 插件

本域拥有 Awaken 插件（Agent Plugin）能力的包格式合规、安装来源、本地存储、启停生命周期、组件注入边界、Desktop 管理面和验收设计。当前 Awaken **不支持插件功能**；本域内容均为已确认但尚未实现的设计约束，不能写成当前能力。

- [插件设计与实施方案](插件设计与实施方案.md)：Agent Plugins 1.0.0 标准合规目标、Codex/Claude Code 参考结论、Awaken 目标架构、数据模型、安全模型、分阶段实施与验收。

两条容易混淆的当前事实仍由原功能域拥有，本域不重复定义：

- Skill 来源枚举中已存在的 `plugin` 来源与 `AWAKEN_PLUGIN_SKILL_DIRS` 环境变量只是技能目录发现的占位来源，不构成插件安装、启停或包格式能力，由 [08 技能](../08_技能/索引.md) 拥有；
- Tool Catalog 中的 `SourcePlugin` 工具来源枚举是预留值，当前没有任何生产 provider 使用它注册工具，由 [04 工具、权限与安全执行](../04_工具权限与审批/索引.md) 拥有。

实施时将改变现有事实的功能域（届时必须同步其权威文档）：

- Skill 的 `plugin` 来源 root 供给、保留 ID 前缀与删除边界：[08 技能](../08_技能/索引.md)；
- MCP 配置 scope、server identity 与合并顺序：[06 MCP 运行时](../06_MCP运行时/索引.md)；
- 本地 HTTP route 清单：[09 AG-UI 与 A2UI 协议](../09_AGUI与A2UI协议/索引.md)；
- Desktop 扩展导航与插件管理页：[01 桌面工作台](../01_桌面工作台/索引.md)；
- 连接器「用户安装」列表与插件认领 server 的边界：[07 连接器](../07_连接器/索引.md)；
- 插件 Hook 若未来实施，必须先修改 [Hook 产品与架构契约](../04_工具权限与审批/Hook产品与架构契约.md)（当前明确不支持 Plugin 自动 Hook）。
