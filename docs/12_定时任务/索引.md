# 12 定时任务

本域拥有用户可配置的循环任务、日程任务、内置模板、无人值守执行、执行历史和恢复语义。

## 当前状态

**实现已落地（首版），固定提醒主链路已完成真实 Desktop 验收，完整门禁尚未完成。** 左侧一级入口、循环/日程任务定义、10 个内置模板、创建/编辑/启停/删除/立即执行/取消、专属线程、执行历史、Core 内调度器与 misfire 恢复、Agent 与固定提醒两类任务均已实现；Agent 编辑器复用 `/` Skill 与 `@` Computer Use/Plugin 结构化选择。固定提醒以 `AWAKEN_SCHEDULED_NOTICE` 事件进入专属线程并在 Desktop 运行时触发原生通知，不伪装成模型回复。Agent 完整模型执行、Computer review/handoff timeout、运行中取消/强杀恢复、原生通知点击和失败矩阵仍待真实 Desktop 补齐。

**首版明确不支持**：Desktop 完全退出后由操作系统唤醒；秒级 Cron/Quartz 特殊字符/自然语言生成表达式；同一任务并发多个 Agent run；用户自定义模板；任意 Connector/channel 作为投递目标；把现有普通线程选为写入目标；对漏掉的多个周期逐条补跑；自动回答 `ask_user` 或自动完成外部授权。

**代码 owner**：
- 定义/触发/状态：`src/scheduledtask`
- Agent/提醒线程与 run 复用：`src/runtime`
- 模型 profile 解析：`src/modelprofile`
- HTTP：`src/server/handlers_scheduled_tasks.go`
- Core 装配：`cmd/awaken-core/main.go`
- Main/preload/shared：`apps/desktop/src/main`、`preload`、`shared/runtime.ts`
- Renderer 页面/模板：`apps/desktop/src/renderer/ScheduledTasksView.tsx`、`scheduled-tasks/*`
- Design System 组件：`Awaken Design System/src/components/AwakenScheduledTasks*`
- 协议/Workbench 提醒卡：`src/protocol/agui`、`apps/desktop/src/renderer/run-narrative/projector.ts`
