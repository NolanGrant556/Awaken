## 真实 Desktop 场景

1. 通过 README 正式入口启动，记录实际随机 loopback 地址和健康检查；关闭后确认 child 退出。
2. 创建多轮线程和附件，重开 Desktop，确认从全局数据根重放且 workspace 无权威 transcript。
3. 在有活动输出时断开/重连，确认 stream cursor 续流不重复；重启后的 durable replay 依 semantic seq 排序。
4. 人为中断一个工具 run 后重开，确认 outcome unknown 被封口且没有重执行。
5. 使用 typed Office 工具转换真实中文 DOCX/XLSX/PPTX；逐页核验 PDF，观察无前台 LibreOffice。
6. 在受控测试环境模拟 runtime 缺失，确认显示 needs-runtime，且普通工具不自行下载或降级到系统 binary。

只读验收不得修改用户现有模型、MCP、Skill、宠物或会话配置；需要删除/损坏测试时使用隔离 userData。

## 证据与完成条件

记录 commit、平台/架构、实际 userData 测试根、启动方式、runtime revision、命令退出码、Desktop 步骤和差异。Office 证据包含源文件、导出文件 hash 和逐页视觉检查；重放证据包含同 thread 重启前后 identity/终态对比。

以下任一情况均不算通过：固定端口 smoke 代替 Desktop、旧截图代替当前运行、PDF 只检查存在性、忽略中段 journal 损坏、持久化失败后继续副作用，或把重启后的合成 interrupted 当成真实工具结果。
