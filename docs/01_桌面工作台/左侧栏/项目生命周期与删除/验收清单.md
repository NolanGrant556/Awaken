# 项目生命周期与删除：验收清单

- [ ] 从 Awaken 移除后目录和历史保留，重启不复活，重新添加可恢复关联。
- [ ] 删除历史后项目和目录保留，UI 立即隐藏历史，后台最终清理 JSONL/附件。
- [ ] active/approval/question run 自动取消，不向用户暴露 `THREAD_BUSY`。
- [ ] 重复请求和响应丢失不会重复删除。
- [ ] Trash 成功后目录真实进入系统废纸篓，历史才逻辑删除。
- [ ] Trash 失败后项目恢复，thread rows、JSONL 和附件不变。
- [ ] Trash operation 超过 30 秒仍未终态时，Renderer 继续后台跟踪；随后失败无需重启即可恢复项目和历史，成功保持移除。
- [ ] Renderer 在后台 operation 未终态时重载，能够从持久化 tracker 续接状态，不因轮询或刷新瞬时失败丢失跟踪。
- [ ] Prepare、staged、trashing、finalize、cleanup 五个崩溃点均能重启续跑。
- [ ] 同路径出现不同文件身份时绝不删除新目录或历史。
- [ ] macOS Trash 与 Windows Recycle Bin 都完成真实 smoke。
