# 04 工具、权限与安全执行

本域拥有 Tool Catalog、provider/capability/dependency、每 run 可用性快照、TaskScope、零审批执行决策、Outcome、当前登录用户 `Bash`、七个模型基础工具，以及保留的 typed 辅助工具。`WorkspaceExecutionBroker` 只服务 `dependency_install`、`git_remote` 和 MCP Artifact bridge；`Bash` 不经过 restricted、supervised、staging 或 broker receipt 路径。

- [工具定义与暴露](工具定义与暴露.md)：目录、provider manifest、环境与工具快照。
- [工具决策、Outcome 与失败监督](工具决策、Outcome与失败监督.md)：默认自动执行、专用 gate、结构化失败与恢复。
- [TaskScope 与路径安全](TaskScope与路径安全.md)：读写根、附件和敏感路径。
- [Bash 本机执行面](Bash本机执行面.md)：当前登录用户 Shell、线程 cwd、前后台任务、真实环境与未观测副作用。
- [Typed 文件工具与可恢复删除](Typed文件工具与可恢复删除.md)：`Read`、`Edit`、`Write`、`Glob`、`Grep` 与 Trash。
- [Artifact 与演示文稿工具契约](Artifact与演示文稿工具契约.md)：当前生成不支持、发布支持、MCP bridge 和历史回放边界。
- [验收](验收.md)：自动化、平台矩阵和真实 Desktop 验收。

受控 `memory` 当前作为内建辅助工具进入 run 固定快照，不属于七个模型基础文件/搜索工具；已实现 action、Markdown 根、Dream maintenance 边界和剩余验收缺口见 [11 长期记忆](../11_长期记忆/索引.md)。

正式 `subagent` 当前作为 root-only 内建编排工具进入 run 固定快照，支持只读 `explore/review` 的 `spawn/status/wait/cancel`；child 不暴露该工具、主动提问或 mutation 工具。任务状态、并发、事件和 Desktop 产品语义由 [02 原生 Subagent 产品与架构契约](../02_主智能体闭环/原生Subagent产品与架构契约.md) 唯一拥有。
