# AwakenSwitch

Awaken 全局布尔启停原子组件。状态完全受控，开启固定使用成功绿色，关闭固定使用中性灰色；关闭不是错误，因此不得使用危险红色。

## Props

- `checked`：当前开关状态。
- `label`：无障碍名称；组件会根据状态生成“开启/关闭”动作说明。
- `busy`：处理中状态，同时阻止重复操作；不改变当前开关颜色、透明度或鼠标光标，避免保存时闪烁。
- `disabled`：禁用状态。
- `size`：`default` 为常规设置与卡片入口，`compact` 为模型等密集控制。
- `onCheckedChange`：用户操作后返回下一状态；持久化和失败恢复由 consumer 处理。

## 边界

- 组件只拥有视觉、键盘焦点、禁用和忙碌交互，不拥有业务状态。
- Skills、连接器、设置、记忆、搜索和 Desktop 旧入口均应消费本原子组件或其兼容语义外壳。
- 状态色来自 Design System tokens，禁止 consumer 覆盖为红色关闭态。
