# 14 插件

本域拥有 Awaken 插件（Agent Plugin）的包格式合规、候选 dry-run/完整导出/安装替换、用户授权在线修改后的 digest CAS commit、模型 Creator surface、安装来源、本地存储、启停生命周期、组件注入边界和验收分层。Desktop 插件页交互由 [01 扩展管理](../01_桌面工作台/扩展管理/插件页产品与架构.md) 拥有；Skill / MCP 被注入后的发现、激活、transport 与 readiness 仍由原域拥有。

- [产品与架构契约](产品与架构契约.md)：当前支持、当前缺口、尚未实现的设计约束、目录与 identity、HTTP 与 owner。

跨域事实不在本域重复定义：

- plugin 来源 Skill 的发现、优先级、预览与删除边界由 [08 技能](../08_技能/索引.md) 拥有；
- `plugin` MCP scope、合并顺序与 `PLUGIN_ROOT` / `PLUGIN_DATA` 由 [06 MCP 运行时](../06_MCP运行时/索引.md) 拥有；
- 连接器「用户安装」排除 `plugin__` server 由 [07 连接器](../07_连接器/索引.md) 拥有；
- `/v1/plugins*` route 清单由 [09 HTTP 与 SSE 接口契约](../09_AGUI与A2UI协议/HTTP与SSE接口契约.md) 拥有；
- Tool Catalog 的 `SourcePlugin` 预留值仍由 [04 工具、权限与安全执行](../04_工具权限与审批/索引.md) 拥有，当前生产插件工具不使用该枚举。
