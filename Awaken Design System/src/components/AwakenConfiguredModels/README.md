# AwakenConfiguredModels

Awaken 当前按接入类型展示的紧凑 LLM 设置卡片。卡片首层使用模型供应商的官方产品 Logo，标题按“厂商名：模型 ID”单行展示，并保留默认与启用控制；接入类型和 Function Calling 能力不作为卡片标签重复展示。卡片统一使用纯色表面和细边框，不使用渐变炫光、悬浮阴影或上浮位移。上下文长度、自动压缩阈值和输出上限放在低高度、可折叠的 LLM 参数区域，其中自动压缩阈值的标题与数值在所属参数列水平居中；操作统一收在单行紧凑底栏。推理强度不在这里设置，只由 Composer 的会话级选择器提供；品牌映射、状态计算与持久化由 consumer 控制。
