# AwakenModelSettings

模型设置页的 UI-only 工作区。页面级标题与一行说明由标准 `AwakenSettings` 页头拥有；本组件只组合左侧接入类型导航、右侧二级页头和内容容器。

模型工作区限制最大阅读宽度，不随超宽窗口无限拉伸。模型页使用标准设置滚动面：展开参数超过窗口高度时，滚轮移动右侧标准页面并保持左侧一级设置导航固定，卡片本身不建立嵌套滚动。当前不使用 168px 轨道、粒子或光晕页头。

连接配置使用固定三列、统一高度的紧凑卡片，只展示官方 Logo、名称和“配置”动作；选择后由 `AwakenSettingsProviderModal` 在屏幕中央承载配置表单与连接状态。供应商读取、凭据、连接测试、保存、重复模型 Toast、删除和运行时能力同步仍由 Desktop consumer 负责。
