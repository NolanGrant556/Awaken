# 插件页产品与架构

本文唯一拥有 Desktop 扩展导航「插件」页的视图、安装/详情交互和失败展示。插件包格式、安装来源、存储、启停与运行时注入由 [14 插件](../../14_插件/索引.md) 拥有；Skill 发现与预览由 [08 技能](../../08_技能/索引.md) 拥有；MCP readiness 由 [06 MCP 运行时](../../06_MCP运行时/索引.md) 拥有。

## 当前支持

扩展导航「插件」与技能、连接器并列。页面列出已安装的 user-scope 插件，提供安装、详情、整体启停、单 server 启停、升级和卸载。Renderer 只通过 Main `requestRuntime` 调用 `/v1/plugins*`，不读写 `~/.awaken/plugins` 或 `plugins.json`。

- 一级「插件」入口和页面空状态通过 Design System `plugin` 概念消费 Agent Plugins 官方 `app/icon.svg` 标记；官方 path 保持不变，仅由图标注册表增加对称透明留白，导航以 20px、空状态以 24px 请求，与同屏主导航图标对齐。列表卡通过 `plugin-default` 消费实心 `puzzle`（Heroicons v2 solid Puzzle Piece，固化进 16 网格），请求尺寸 20px。Desktop 不内联或复制 SVG。
- 插件页直接消费 Design System `AwakenPlugins` Catalog 组合：统一标题与操作区、带图标搜索、双列卡片，以及加载、无结果、未安装和错误状态；窄窗口收敛为单列。列表卡继续消费 `AwakenPluginCard`，展示名称、版本、描述或首条诊断、`N skills / M servers` 与 compact 启停开关；卡片主体打开详情，开关不打开详情。
- 安装弹窗消费 `AwakenPluginInstallDialog`：本地目录/zip 与 HTTPS URL（zip 或 git，可选 ref/subpath）；来源使用统一分段选择，输入、替换选项与风险确认分层展示。同名默认 abort，勾选「替换」才走 Trash replace。无沙盒说明与强制确认位于同一警示区；确认安装前必须勾选「MCP 子进程无沙盒，并以当前用户身份运行」。本地浏览复用已有 `pickDirectory`；zip 也可手填路径。
- 详情弹窗消费 `AwakenPluginDetailDialog`：来源、digest、诊断、skills 列表、MCP server 短名 + readiness + 单 server 开关、升级与卸载。Skill 预览复用既有 `SkillPreviewDialog` 与 `POST /v1/skills/preview`；plugin 来源不可删除。卸载前有确认，说明包和数据目录一并进入回收站。
- 技能页把 plugin 来源条目放在全局视图的「其他来源」，来源小字为 `插件 · <plugin-name>`；删除入口保持禁用。连接器「用户安装」不显示 `plugin__` 前缀 server。
- 启用 Plugin 同时进入 Workbench 与定时任务 Agent 编辑器的 `@` 目录；禁用、升级、卸载或模型 Creator install/replace/commit 成功后，Store mutation 发布 composer catalog revision，使保持打开的目录重新读取。Plugin token 的 digest 复验与 model-facing 引导由 [14 插件](../../14_插件/产品与架构契约.md) 拥有，本页不复制输入或运行时状态。
- `PluginStore` 不可用或 `plugins.json` 损坏时，列表请求失败并展示错误，不影响技能/连接器页与 Desktop 启动。
- 模型创作面不新增 Renderer 文件编辑器或手动「接受 digest」按钮：bundled `plugin-creator` 默认通过 strict-v2 `plugin` 工具执行 inspect、完整包 export、候选 validate 与安装/Trash 替换。用户在当前请求明确授权直接修改已安装包时，Creator 先固定 inspect 返回的 recorded digest，只编辑该 `PLUGIN_ROOT`，然后用 `plugin action=commit` + `expected_digest` 完整校验并 CAS 签收。未提交或提交失败的漂移继续在本页显示 `plugin_digest_changed` 并保持不可用；成功 commit 触发与其他 Store mutation 相同的 `onChange`，刷新 Skill/MCP roots 与 catalog revision，本页以新 digest 重拉后不再显示漂移错误。本页仍是启停、升级、卸载和诊断详情的可视管理面。

## 当前不支持或已知缺口

- 真实 macOS Desktop 已覆盖授权在线修改 commit：模型以 `Edit` 直改已安装包、commit 后页面重拉新版本/新 digest 且无漂移诊断，后续新 run 能通过结构化 Plugin 选择调用更新后的 Skill；完整 2.1 安装来源、带 MCP 调用、启停、升级、损坏恢复与卸载组合矩阵仍未在本环境完成。
- 无 marketplace 浏览、无 legacy manifest 安装入口、无项目 scope 插件。
- 生产 Linux 上平台 Trash 不可用时，replace/卸载 fail closed，与 Skill 删除同语义。

## Owner

- `apps/desktop/src/renderer/ExtensionsView.tsx`：插件分区状态、安装/详情编排与 runtime 回调。
- `apps/desktop/src/main/index.ts`、`preload/index.ts`、`shared/runtime.ts`：`/v1/plugins*` typed bridge。
- `Awaken Design System/src/components/AwakenPlugins/`、`AwakenPluginCard/`、`AwakenPluginDetailDialog/`、`AwakenPluginInstallDialog/`：UI-only Catalog 组合、组件与 Gallery。
- `src/server/handlers_plugins.go`：HTTP DTO。
