# 验收

## 1. 自动化

至少覆盖：

- Desktop supervisor 的 start/reuse/stop、稳定 userData 和固定 `AWAKEN_HOME` 注入；user MCP 配置只使用 `AWAKEN_HOME/config/mcp-servers.json`，不读取、迁移或 fallback Electron `userData`/旧配置路径；空 `AWAKEN_DEFAULT_WORKSPACE` 时 user MCP 管理仍完整可用且 project scope 不参与；
- SemanticJournal kind、append-before-side-effect、terminal、orphan recovery、live/replay 同 projector；
- `memory_recalled` / `memory_mutated` 只耐久 identity/action/revision/count 等无正文 receipt；Dream task/report 使用独立 durable store，重启后 terminal task 可由 Desktop 重放且不伪装成 thread journal record；
- composer Skill turn 的完整 `user_message` 先于预激活，失败保留输入、多 Skill activation 批次不泄漏部分记录，成功路径不重复写入；
- 已校验 composer Skill token 在最终 provider request 中形成 host-owned、current-run-scoped selection block，包含 Skill ID/source/activation mode/absolute root/absolute SKILL.md；single/multi/token-only/fork 与历史恢复边界都有合同测试；
- Skill activation/resource receipt 的压缩、重启和 fork 隔离；
- 消息工具只产生普通 tool call/result，不产生审核 kind 或 pending review；
- 环境快照有界、去敏、native/translation、typed env refs、workspace marker symlink fail-closed、canonical executable path/fingerprint、短期版本缓存和 OS PATH 规则；version child 必须使用最小环境 + 空 HOME，`SECRET_CANARY` 不得进入 version/warning/snapshot，非 host-trusted executable 不执行；Skill roots/临时根/refresh reason 必须进入 identity 且 clone 不共享 slice，非绝对根被拒绝，最多 64 项；
- Desktop supervisor 的 login env 解析真实覆盖 PATH/HOME/canary，3 秒超时、256 KiB 上限、marker framing、失败回退且不输出环境值，合并后仍清除 LLM 配置变量；Core snapshot/transport 共用解析后的环境，完整 PATH 通过 digest/entry count/truncated 绑定，130-entry 末尾 canary 不被预览上限截断；显式 shell-config PATH 静态探测只接受安全字面赋值，不执行 rc，对单引号、可执行语法、非法路径、取消/超时回落 `process_environment` 并保留 warning/provenance；
- generic dependency observation 与 candidate install plans 只由 host manifest + pinned snapshot 生成且不自动执行；
- open-network installer 必须拒绝 workspace/temp/Skill root 内的 manager，并从 child PATH 剔除这些根和不可解析目录；外部 `/usr/bin/env` manager 仍可运行，但 workspace fake interpreter 不得被调用；
- run-start、explicit refresh 和 dependency install 的 reason 分别为 `run_start`、`explicit_refresh`、`dependency_install:<plan_id>`；旧 ToolRuntime 快照不被原地替换，Skill root 元数据不导致 Skill 正文 preload 或脚本执行；
- provider 显式 Python/Node package probe 的安全 ID、只读解析、去敏最小环境、超时/cache、workspace search path 和有界版本约束；Node 主入口可解析但 `package.json` 未导出时仍为 ready，不把 `ERR_PACKAGE_PATH_NOT_EXPORTED` 当成缺包，且 probe 不执行入口代码；
- `Bash` 使用当前登录用户环境，不对 workspace 外写入、网络、包管理器、安装脚本、raw delete 或协作 CLI 引入审批/白名单；子进程用 canary 证明 `HOME`、代理、证书、用户缓存和 Homebrew PATH 继承，不输出当前机器的真实敏感值；前台默认 120 秒、最大 600 秒，线程 cwd 隔离，后台任务归属线程并可清理；`Bash` 不经过 restricted/staging broker；
- host Work 依赖 resolver 必须覆盖 PATH、显式绝对路径、macOS Applications、Windows Program Files/LocalAppData、组件级 probe 和安装后立即重探；缺少依赖不得阻止 Desktop/Core 启动；
- 旧 `<userData>/runtimes/primary-runtime` 一次性删除必须限定精确路径、拒绝 symlink root、幂等且失败不阻止启动；
- 七工具 runtime 不注册 Office worker 或 typed artifact runtime；Office/PDF/图片等文件由 `Bash`/`Write`/Skill 生成后显式 `artifact_publish`，历史 typed artifact record 仍可回放；
- Desktop/打包脚本不得引用 prepare/check/package/install primary runtime，也不得产出 runtime archive。

聚焦命令：

```bash
go test -count=1 ./src/runtime ./src/agentcore ./src/protocol/agui ./src/tool ./src/tools/bash ./src/tools/read ./src/tools/edit ./src/tools/write ./src/tools/glob ./src/tools/grep ./src/tools/web_search
go test -count=1 ./src/tools/dependency_install
AWAKEN_LIVE_DEPENDENCY_INSTALL_SMOKE=1 go test -count=1 -run '^TestLivePinnedPureWheelDependencyInstall$' -v ./src/tools/dependency_install
```

最后一条是需要网络、真实 pip 和 Darwin Seatbelt 的 opt-in smoke：它在空临时 workspace 安装 pinned pure wheel，必须同时证明 post-probe ready、workspace-local observed path、`dependency_install:<plan_id>` reason 和 committed broker receipt；未设环境变量时正常 skip。

## 2. Desktop 验收

必须按根 README 的 `open:desktop` 打开真实 `Awaken Dev`，验证服务重启、旧线程重放、inline/fork Skill、provider readiness，以及消息工具不会恢复为待审核状态。安装版存在时不得被开发入口关闭。还必须验证：缺少 Python/LibreOffice/Poppler/FFmpeg 不阻止 Desktop；已有工具被直接复用；一个真实缺失依赖由 Agent按 Skill/Shell 安装后重试成功，后续 run 不重复安装。Gallery、mock、直接 Core API 和旧截图只能辅助。

## 3. 完成边界

本轮未实际执行的 Desktop 或 Windows/Linux 实机步骤必须逐项报告。自动化通过不等于 host 依赖发现、Agent 安装或文件生成与发布链路在所有平台通过。
