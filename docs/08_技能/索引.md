# 08 技能

本域拥有 Universal Skill 的包格式、来源、发现优先级、目录状态、调用、资源读取、候选 dry-run/完整导出/安装替换、Creator 编排、fork、持久恢复与 MCP 动态来源边界。plugin 来源的安装、启停与 root 供给由 [14 插件](../14_插件/索引.md) 拥有。工具目录、权限和执行结果由 [04 工具权限与审批](../04_工具权限与审批/索引.md) 拥有；MCP 传输和连接生命周期由 [06 MCP 运行时](../06_MCP运行时/索引.md) 拥有。

- [技能包与加载契约](技能包与加载契约.md)：来源、优先级、frontmatter、状态和兼容格式。深度研究目标入口不是用户 Skill，也不进入 Skill catalog；见 [16 深度研究](../16_深度研究/索引.md)。**当前不支持**。
- [安装与激活契约](安装与激活契约.md)：目录预算、用户/模型调用、composer 当前选择的确定性绑定、正文/资源按需加载、candidate dry-run/export/install/replace、Skill 初始化与上下文恢复。
- [执行模式与 MCP 来源边界](执行模式与MCP来源边界.md)：inline、真实 child-agent fork、MCP prompt/resource 动态 Skill。
- [验收规范](验收规范.md)：自动化、重启与真实 Desktop 验收。
