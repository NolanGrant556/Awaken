# 技能页产品与架构

本文唯一拥有 Desktop Skills 管理页的视图顺序、内置资源同步、展示和失败降级。Skill 包格式、发现优先级、激活与 Core 删除安全边界由 [08 技能](../../08_技能/索引.md) 拥有。

## 当前支持

Skills 管理页有四个固定视图，顺序为 `Awaken Skills`、`项目 Skills`、`全局 Skills`、`Agents Skills`，每次进入页面默认选择 `Awaken Skills`。

- `sourceOrigin="bundled"` 只进入 Awaken Skills，来源标签为“Awaken 内置”；
- project 条目进入项目视图，并继续按项目根分组；
- user 条目进入全局视图；MCP 与其他动态/外部来源继续在全局视图的既有分区展示；
- `sourceOrigin="agents"` 进入 Agents Skills 视图，展示来自 `~/.agents/skills` 与 `<workspace>/.agents/skills` 的包；agents 来源是只读兼容来源，卡片不渲染删除按钮，但可预览 `SKILL.md`；
- bundled 卡片是不可点击的静态展示，完全不渲染删除按钮，也不提供 `SKILL.md` 预览；project/user 卡片可发起确认删除；MCP、agent 与其他非安装生命周期来源保留原有禁用删除入口；
- 除 bundled 外，拥有本地 `SKILL.md` 和 Core `catalogEntryId` 的卡片主体是可聚焦的详情按钮；删除按钮是独立兄弟操作，不会打开详情。MCP 动态 Skill 没有本地文件，不提供详情按钮；
- 安装弹窗只提供 project/global，不允许把上传内容安装成 bundled；
- 资源根随附 `word` / `excel` / `ppt` / `pdf` / `code-search` / `PDF_Max` 六个 Skill 包；Word 的“接受全部修订”走文档化的 `pandoc --track-changes=accept` 命令，包内不含 `accept_changes.py` 辅助脚本；`code-search` 以内联上下文编排现有 `WebSearch`；`PDF_Max` 不携带 Typst 二进制，由 Agent 按正文检查固定 Awaken toolchain 路径和系统 PATH，缺失时安装固定受测版本；
- bundled 目录为空时显示“内置 Skills 未就绪，重启 Awaken 后重试”，不影响其他视图和 Desktop/Core 启动。
- Skills 页面由最外层 Desktop 内容区拥有唯一纵向滚动；居中的内容层只负责最大宽度与左右留白，不拥有独立滚动，因此页面滚动条始终贴近内容区右边界，而不会随内容列向内缩进。
- Skills 工具栏缩窄时保持四个来源标签单行完整显示，搜索框在 `360px` 到 `160px` 之间优先随可用宽度收缩；视口进入窄屏断点后，标签和搜索框再切换为上下两行，避免用标签换行承担搜索框的固定宽度。
- Desktop 项目 Skills 视图与 Design System 的 Skills 组合都直接消费原子 `AwakenFolder`，使用 `dense` 尺寸并按可用宽度自动填充列，让宽屏优先容纳更多项目而不是保留固定五列后的空白；点击文件夹打开受控的 `AwakenProjectSkillsDialog`，主页面不再向下追加项目详情面板。项目名称只在窗口标题中出现，内容区不重复名称，只保留完整路径、数量和 Skill 卡片；点击卡片主体切换到 `SKILL.md` 预览，关闭预览后返回原项目窗口；project 卡片的删除按钮打开确认窗口，取消或成功删除并刷新后返回原项目窗口。Skill 启停直接或经兼容外壳消费原子 `AwakenSwitch`。这些 Design System 组件只拥有 UI，项目数据、预览、删除和启停副作用仍由 Desktop 注入。

### `SKILL.md` 只读预览

点击非 bundled 的可预览卡片后立即打开约 `920 × 720` 的阅读 Dialog；视口不足时再自适应收缩。Awaken 内置 bundled 卡片保持静态，点击不打开任何详情。Dialog 视觉上只保留固定关闭按钮；关闭按钮保留 `aria-label="关闭"` 供辅助技术使用，鼠标悬停或键盘聚焦时不显示可见 tooltip 或原生 `title` 提示。标题仍以 visually-hidden 形式提供给辅助技术，不显示名称、来源、元数据摘要、提示条、footer、“使用”、复制、编辑或包内资源/脚本列表。

正文是 Dialog 中唯一的纵向滚动容器，并作为初始焦点，因此鼠标滚轮、触控板、方向键、Page Up/Down、Home/End 都作用于完整文档。关闭后恢复卡片焦点；关闭或切换条目时回到顶部，较早请求晚返回时不得覆盖当前条目。

滚动内容固定按以下顺序展示：

1. 包含原始 `---` 分隔线、字段顺序和未知字段的完整 YAML frontmatter，以安全的 `<pre><code>` 文本显示；
2. frontmatter 之后的完整 Markdown 正文，支持 GFM 标题、列表、表格、代码块、引用和只读任务列表。

代码块与宽表格只允许自身横向滚动，不建立第二个纵向滚动区。预览关闭 raw HTML、脚本、Mermaid 执行和外部图片请求；相对链接不解析，只有 `http`/`https` 外部链接可点击。主题色、遮罩、代码、表格、引用、链接和滚动条全部来自 Design System token，Dialog 打开时切换浅色/暗色会立即继承新 token。

## 内置资源同步

Desktop 在启动 Core 之前同步内置资源：

```text
开发版 <appPath>/resources/system-skills
安装版 <resourcesPath>/system-skills
                    │
                    ▼
        ~/.awaken/skills/system-skills
                    │
                    ▼
 AWAKEN_BUNDLED_SKILL_DIRS（Desktop 固定注入）
                    │
                    ▼
        Core 现有 /v1/skills Catalog
```

Desktop 先清除登录环境继承的 `AWAKEN_BUNDLED_SKILL_DIRS`，再注入上述产品固定目标，Shell profile 不能改变产品内置来源身份。同步不新增 HTTP route、Core 特权或 Renderer 文件访问能力。

目标中的 `.manifest.json` 是 Desktop 内部协议，`schemaVersion` 固定为 `1`，包含 `appVersion` 和按 POSIX 相对路径排序的 SHA-256 文件表。每次启动都重新扫描源与目标；清单文件本身不能代替实际文件核对。缺失、修改、额外文件或版本变化都会触发完整目录替换。

同步只接受真实目录和普通文件，拒绝 symlink、特殊文件和源中的保留 `.manifest.json`。更新使用目标同父目录下的 staging、backup 与 rename；中断遗留会在下一次启动先恢复，交换失败则恢复最后完整目标。

## 失败与恢复

- 源缺失、源非法或首次同步失败：记录结构化 `system_skills_sync_failed`，Core 以无 bundled Skill 的状态继续启动；
- 已有完整目标但升级失败：保留或恢复旧目标，Core 继续使用它；
- 用户手工修改 Desktop-owned 目标：下一次成功同步按资源源覆盖；
- 目标同步成功但没有实际 Skill 子包：Awaken Skills 保持空态，不生成 invalid 卡片。
- 预览期间文件消失、身份过期、路径/realpath 校验失败、非 UTF-8 或超过 2 MiB：正文区域显示明确错误，不展示截断内容，也不回退为 Renderer 直接读文件。

## 当前不支持或待验收

- 内置 Office 与 Typst PDF Skill 的真实模型端到端调用（生成文件 → 视觉 QA → `artifact_publish`）尚未完成实机验收；验收项与状态按 [08 技能验收规范](../../08_技能/验收规范.md) 执行；
- 本合同不改变 MCP、Skills runtime、Workbench 布局或 Office 生成依赖；LibreOffice、Poppler 仍是用户机器上的系统依赖，不随 App 分发。

## Owner 与自动化

- `apps/desktop/src/main/system-skills-importer.ts`：路径、清单、校验、恢复与原子交换；
- `apps/desktop/src/main/runtime-supervisor.ts`：清理继承变量并注入固定 bundled 根；
- `apps/desktop/src/renderer/ExtensionsView.tsx`：Tab、分组、标签、空态、详情与删除入口投影；
- `apps/desktop/src/renderer/SkillPreviewDialog.tsx`：按需加载、过期请求隔离、滚动状态和只读文档投影；
- `Awaken Design System/src/components/AwakenDialog`、`AwakenMarkdownRenderer`、`AwakenFolder`、`AwakenSwitch`、`AwakenProjectSkillsDialog`、`AwakenSkillCard`：大尺寸/隐藏标题/初始焦点、安全 Markdown、共享项目入口与开关原子视觉，以及项目窗口和受控删除入口；
- `apps/desktop/electron-builder.yml` 与 `scripts/clean-desktop-package.mjs`：资源打包与源资源保留；
- 对应测试覆盖同步矩阵、Runtime 环境、Renderer 视图与打包生命周期；测试不使用真实 `~/.awaken`。
