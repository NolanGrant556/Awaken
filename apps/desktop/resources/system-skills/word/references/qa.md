# Word QA 清单

## 内容

- 标题、日期、单位、币种、版本、来源与行动项是否正确；
- 是否残留占位文本、示例行或模板说明；
- 目录条目、内部链接、脚注和引用是否对应；
- 修订接受/保留状态是否符合用户要求。

## 结构

- ZIP 中无绝对路径、`..`、反斜杠路径、符号链接或重复部件；
- `[Content_Types].xml`、根关系和 `word/document.xml` 存在；
- 所有 XML 可解析；
- 内部 relationship target 均存在；
- 批注正文、关系、content type 和可见引用相互对应；
- 修订节点包含作者、日期和 ID。

## 视觉

- 每一页都查看，不只看首页；
- 页边距、页眉页脚、页码和分页稳定；
- 表格没有超宽、截断、孤立表头或异常跨页；
- 图片比例、清晰度、题注和环绕正确；
- 中文、数字、标点和中英文混排没有字体回退；
- 不出现空白项目符号、单独落页标题或大块意外空白。
