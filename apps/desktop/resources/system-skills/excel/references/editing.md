# Excel 现有文件编辑

## 编辑前

1. 保留原文件；
2. 运行 `inspect_workbook.py`；
3. 识别 sheet、隐藏行列、冻结窗格、merged range、命名区域、表格、数据验证、条件格式、图表、宏和外链；
4. 找出模板指定的输入单元格和样式规则；
5. 只修改用户要求的区域。

## 保存策略

- 默认输出到新文件；
- `.xlsm` 使用 `keep_vba=True`，保存后确认 `xl/vbaProject.bin` 仍存在；
- `data_only=True` 加载的 workbook 永不保存；
- 外部链接存在时不要调用重算脚本；
- 对 openpyxl 无法维护的扩展，优先通过 LibreOffice/Excel 原生路径处理，或明确报告限制。

## 格式

- 复用相邻单元格的字体、填充、边框、对齐和数字格式；
- 不逐个创建大量不同 style 对象；
- 列宽和行高根据真实内容调整；
- 表头、筛选、冻结窗格和打印区域保持一致；
- 修改公式区域后检查条件格式和图表引用范围是否仍覆盖新数据。
