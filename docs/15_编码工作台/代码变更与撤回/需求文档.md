## 背景与目标

编码工作台要让用户看清智能体修改了哪些文件，并在边界明确时撤回这些修改。首期包括：

- 基于文件检查点的差异，覆盖非 Git 项目，取消运行后不丢失已发生的增量。
- 文件级和轮次级撤回，检测外部修改，明确 Bash 写盘无法保证撤回。
- 只读 Git 观察、状态条和可配置防护。
- 项目编码环境配置。

验收以这些具体行为为准，不以与其他产品“能力相当”作为完成条件。

## 非目标与边界

- **不做 IDE**：不提供多光标编辑器、LSP、断点调试、终端面板。右侧栏代码文件继续只读预览（CodeMirror 6），代码编辑的执行者是 Agent，不是用户手工在 Inspector 改代码。
- **不引入 `apply_patch`**：编辑原语维持 `Edit`（精确替换 + `replace_all`）与 `Write`（整文件），与 Claude Code 同构。Codex 的 freeform Lark 语法 patch 依赖特定模型的 freeform tool 训练，Awaken 是多 provider 产品，不具备该前提。[04 工具定义与暴露](../../04_工具权限与审批/工具发现与执行/实现方案.md) 中“注册快照不得出现 `apply_patch`”的约束保持不变。
- **不做 OS 沙箱**：Codex 的 Seatbelt/bubblewrap/Windows token 沙箱是独立的大型安全工程，不在本方案范围。`Bash` 维持 [Bash 本机执行面](../../04_工具权限与审批/命令执行/实现方案.md) 的当前登录用户直执行合同；本方案的防护是命令级拦截（Hook 层），不冒充 OS 隔离。
- **不新建通用审批 UI**：Awaken 零审批契约保持。敏感 Git 命令防护通过既有 Hook runtime 的内置 preset 实现 block + 改道 `ask_user`，不新增 `awaiting_approval` run 状态或逐工具审批面板。
- **不自动 merge**：Subagent `git_worktree` 的“host 不自动合并”不变量保持；“变更”面板对 worktree 只做审阅呈现，整合仍由主 Agent 显式执行。
- **撤回不覆盖 Bash 写盘**：与 Claude Code 完全相同的边界——checkpoint 只跟踪 typed mutation 工具（`Edit`/`Write`/`trash_file`）以及被 [模型工具合同](实现方案.md#模型工具合同) 文本编辑拦截改道 typed `Edit` 的 Bash 单文件替换；其余 `Bash` 写盘、外部编辑器、Git 命令造成的文件变化不进 checkpoint，UI 必须明示（[模型工具合同](实现方案.md#模型工具合同)）。
- **不做云端执行、CI、PR 评论集成**：`gh`/`glab` 等由模型经 `Bash` 使用用户自己的环境与凭据，与两个对标产品一致。

## 右侧栏“变更”面板

### 入口与信息架构

Inspector 入口顺序改为：

“变更”入口在当前 thread 存在至少一个 checkpoint 或 turn diff 时出现；空 thread 不出现。点击进入变更工作区（复用文件工作区的扩展/收起、宽度与折叠规则，不新建第二套布局状态机）。

面板自上而下：

1. **Git 状态条**（仅 git 项目）：当前分支、ahead/behind、staged/unstaged/untracked 计数、head 短 SHA；数据来自 [事件、Journal 与协议](实现方案.md#事件journal-与协议) status 接口，进入面板时拉取 + 每次 run 终态后刷新，不做常驻轮询。存在 Subagent worktree receipt 时追加一行“子任务分支 awaken/subagent-…（待审阅）”，点击展开该分支相对 base 的 diff（经 status 接口的 worktree 扩展查询）。
2. **turn 时间线**：按 run 倒序列出 checkpoint 节点：用户消息摘要、时间、变更文件数、+n/−m 行汇总；节点展开显示文件列表（路径、change kind、行数徽标、`unsnapshotted` 警示）。+n/−m 与文件列表来自 [事件、Journal 与协议](实现方案.md#事件journal-与协议) 去 git 化后的 checkpoint 基线 turn diff，**非 git 项目功能完整**；Git 状态条缺席不影响时间线与 diff 视图。
3. **diff 视图**：选中文件后右侧（或扩展态主区）显示行级 diff，unified/side-by-side 可切换，语法高亮沿用现有 CodeMirror 语言包。
