# AG-UI 与 A2UI 协议边界

## 1. 权威范围

本文唯一拥有 Awaken 内部事件、对外 wire、Desktop consumer、Design System 和外部参考项目之间的层级边界。不负责逐字段定义、具体 route 语义或 UI 展示规则。

## 2. 当前产品形态

`cmd/awaken-core` 是由 Awaken Desktop 监督的本地服务进程，不是用户独立操作入口。Desktop 启动时先向操作系统申请空闲 loopback 端口，再通过 `AWAKEN_CORE_ADDR=127.0.0.1:<port>` 启动 core 并等待 `/health`。因此运行地址必须从 supervisor 状态获得，不能硬编码 8787。

Awaken 对外发送 AG-UI-compatible event name 和 JSON shape，但 runtime、adapter、SSE server、重放和 Desktop consumer 都由本仓库实现。上游 AG-UI 只作参考，不是运行时依赖或源码 vendor。

## 3. 分层与单向依赖

```text
Tool / Agent loop
  -> agentcore.AwakenEvent 或 durable SemanticRecord
  -> runtime EventBus / Journal
  -> src/protocol/agui mapper 或 semantic projector
  -> src/server HTTP + SSE
  -> apps/desktop TypeScript consumer
  -> renderer reducer / narrative projector
  -> @awaken/design-system props
```

不可绕过的边界：

1. `src/agentcore` 不 import `src/protocol/agui`；内部业务状态不能以 Desktop wire 类型为模型。
2. live 与 replay 必须共用 `src/protocol/agui/semantic_projector.go`，不能各自发明事件含义。
3. Go wire 是 producer authority；Desktop 类型应跟随 Go，而不是靠 TypeScript 可选字段容忍漂移。
4. Renderer 不直接读 journal 或本地文件来补协议；需要的新事实先进入 Core 的耐久语义记录和 wire。
5. Design System 只接受 props/callbacks，不得 fetch、订阅 SSE、调用 Electron IPC、访问 `window.awaken` 或 import AG-UI/A2UI。
6. Electron main 负责进程和受信任 OS 能力；renderer 不能用协议事件里的任意路径直接打开文件。

## 4. 当前专用人工 gate

当前没有通用 `ApprovalCard` 或 `/approvals/{id}/resolve` 主路径。协议只承载两类专用等待：

- 群发消息：`AWAKEN_MASS_MESSAGE_REVIEW_REQUESTED/RESOLVED` 与专用 resolve route；
- 主动提问：`AWAKEN_USER_QUESTION_REQUESTED/RESOLVED` 与专用 answer route。

工具 permission decision 是自动决策和可观察事件，不等于通用人工审批。安全决策枚举和工具边界由 04 域定义。

## 5. Artifact 边界

Artifact wire 表示 runtime 可见的产物记录，不保证文件存在、安全可打开或适合最终交付。Desktop 中间区负责投影；Electron main 打开前必须从 durable transcript 反查 `{threadId, runId, artifactId}` 并复验 role、status、终态、扩展名、OutputRoots、realpath、symlink 和普通文件状态。

Artifact producer、持久化和最终展示分别属于 04、03、01；本文只拥有它们跨进程传输的字段。

## 6. A2UI 当前边界

当前 Awaken：

- 不生成 A2UI surface payload；
- 没有 A2UI parser、catalog、renderer 或 SDK；
- 不执行 generated A2UI action；
- 不用 A2UI 替代群发审核、主动提问或工具权限；
- 不把 Design System 组件自动暴露成 A2UI catalog。

代码中残留的 `.a2ui-*` CSS 只是无对应 runtime 的样式遗留，不能据此宣称部分支持。新增 A2UI 必须先建立协议 schema、可信 action 边界、renderer owner、持久化/重放和安全验收，不能只接一个 JSON renderer。

## 7. 异常和降级

- 未知内部事件映射为 `AWAKEN_UNKNOWN_EVENT`，保留 `rawType`；消费方不得把未知事件当成功。
- 缺失或漂移字段应在 producer/consumer 契约中修复；不得依赖 UI 猜测字段别名作为长期兼容层。
- SSE 断开按 cursor 重连；不能以重新开始一个 run 代替续传。
- Core 不健康时 Desktop 报 runtime lifecycle 错误；不得静默切到固定 8787。
