# 定时执行与提醒 · 需求文档

用户创建循环任务或日程任务，选择智能体执行或固定提醒，并查看运行历史。Desktop 完全退出后任务不运行。

代码、接口和验证方法见[实现方案](实现方案.md)。

## 范围与实现状态

定时任务首版已实现。固定提醒主流程已有真实 Desktop 证据，完整 Agent 执行和故障恢复仍需补齐验收。

**当前支持（首版）：** 左侧一级入口、循环/日程任务、10 个内置模板、创建/编辑/启停/删除/立即执行/取消、专属线程、最近 50 条执行历史、Core 内调度器与 misfire 恢复、Agent 与固定提醒两类任务。固定提醒以 `AWAKEN_SCHEDULED_NOTICE` 进入专属线程并在 Desktop 运行时触发原生通知，不伪装成模型回复。

**已确认并已在首版实现的目标：**

1. 左侧一级导航在“技能”正下方增加“定时任务”，顺序固定为“连接器 → 技能 → 定时任务”。
2. 支持五段式 Cron 循环任务和指定时间的日程任务；日程任务可以不重复、按天重复到截止时间或按次数结束。
3. 支持创建、编辑、启停、删除、立即执行、取消当前执行和查看最近执行记录。
4. 复刻 Qwenpaw 的“从模板创建”主流程与 10 个内置模板：选模板只预填编辑器，用户确认保存后才创建任务。
5. Agent 任务复用 Awaken 当前 RunService、模型 profile、TaskScope、工具/Skill、SemanticJournal 和项目线程；不建立第二套 Agent loop。
6. 固定提醒不调用模型，不伪造成 assistant 回复；它以 host-owned 定时提醒事件进入专属线程，并在 Desktop 运行时触发原生通知。

## 产品范围

### 首个可交付版本

首版必须同时交付：

- 左侧一级入口；
- 空状态、任务列表和状态汇总；
- 普通创建与从模板创建；
- 循环/日程表单；
- 项目、任务类型、内容、时区、profile、超时和漏跑宽限配置；
- CRUD、启停、立即执行、取消当前执行；
- 最近 50 条执行记录；
- 每任务稳定专属线程和从执行记录打开线程；
- Core 重启恢复、misfire、单任务防重入和全局并发上限；
- Agent 与固定提醒两种任务；
- 10 个模板及动态未来时间默认值；
- 自动化测试和真实 Desktop 视觉证据。

### 首版明确不支持

- Desktop 完全退出后由 launchd、Task Scheduler 或其他 OS 后台服务唤醒；
- 多设备、云端或团队同步；
- 秒级 Cron、Quartz 特殊字符、自然语言直接生成表达式；
- 同一任务并发执行多个 Agent run；
- 用户保存自定义模板、模板市场、模板导入导出；
- 任意 Connector/channel 作为直接投递目标；
- 把现有普通线程选为写入目标；
- 对漏掉的多个周期逐条补跑；
- 未经独立安全设计的“忽略工具边界”“自动回答 ask_user”或自动完成外部授权。

### 后续增强

列表和模板闭环验收通过后，可以增加 Qwenpaw 同类的月历视图。月历只投影 `calendar` 日程任务的未来 occurrence，点击项目仍打开同一编辑器；它不是第二份任务 authority。该增强不阻塞首版“从模板创建”。

## Desktop 产品行为

### 入口与页面

“定时任务”消费 Design System `scheduled-task` concept 的时钟图标，`activeNavId="scheduled-tasks"`。选择后中间内容区显示独立 `ScheduledTasksView`；它与 `ExtensionsView` 平级，不塞入 Connector 或 Skill section。切换页面不得改变当前项目、活动 thread 或进行中的 run。

页面顶部：

- 标题“定时任务”；
- 说明“按计划自动执行提醒或 Agent 任务；Awaken 退出期间不会运行”；
- 主按钮“创建任务”；
- 次按钮“从模板创建”；
- “刷新”动作。

列表每项至少显示：

- 名称、类型（提醒/Agent）、所属项目；
- 人类可读计划和时区；
- 启用状态；
- 下次执行时间；
- 最近一次状态和时间；
- “立即执行”“执行记录”“编辑”“删除”；
- 运行中时显示“取消执行”，而不是再次运行。

空状态必须同时提供普通创建和模板创建，不展示静态假任务。

### 普通创建

编辑器按以下顺序组织：

1. **基本信息**：名称、启用；
2. **运行位置**：通过单一下拉选择器选择一个 active project，候选项目在弹层内可搜索、可滚动，不随项目数量扩展表单高度；零文件夹项目允许选择；
3. **调度**：
   - 循环任务：每小时、每天、每周、自定义五段 Cron；
   - 日程任务：开始时间、是否重复、每 N 天、永不结束/截止时间/限定次数；
   - IANA 时区，默认读取系统时区；UI 使用自有中文可搜索选择器，主文案和列表不直接暴露 IANA ID，按计划日期计算中文偏移，但保存值仍是原 IANA ID；
   - 日程日期时间使用 Design System 自有中文日历与小时/分钟控件，draft 仍输出 `YYYY-MM-DDTHH:mm`，不得回退为 Chromium 原生 `datetime-local` 弹层；
4. **任务内容**：
   - `reminder`：固定提醒正文；
   - `agent`：给 Awaken Agent 的 prompt；输入框复用首页 Composer 的 `/` Skill 与 `@` Computer Use/Plugin 目录、collapsed caret 解析、句中 trigger 替换、完整结果滚动、筛选、键盘选择、catalog revision 刷新和结构化 token 展示，并直接继承同一套正文、图标、字重、基线与间距，不维护定时任务专用缩放、偏移或只能从左到右输入的 trigger 状态；marker 必须位于文本 segment 行首或由 whitespace 直接引导，先写完整句子后移回句中补空格再输入 marker 仍可触发，紧邻普通文字的 marker 不触发；选择后只替换当前 caret 对应 query 并保留后续正文；`/` 仍只展示所选项目范围内 `loaded && userInvocable != false && sourceOrigin != "plugin"` 的 Skill，`@` 始终提供内置 Computer Use，并追加已启用且含可用 Skill 或 MCP 的 Plugin；
   - `/`、`@` 选择分别保存结构化 Skill、Computer Use capability 或 Plugin identity，不把名称或宿主引导扁平化进 prompt；提醒正文不显示命令菜单，也不能保存 Composer token；
   - Plugin 目录为空不影响 Computer Use 出现；`@` 查询对 capability 与 Plugin 使用同一过滤，两类结果都无命中时显示“没有匹配的能力或 Plugin”；
5. **模型**：任务可保存一个显式 profile ID；留空时按“`scheduled_task` 用途 profile → 当前默认 ready profile”在每次触发时重新解析。候选项消费与 Composer/设置相同的 enabled/ready 目录，前端只显示实际 model ID，不附加 Chat、Responses 或 Messages 等协议文案；选择值仍使用 opaque profile ID，因此展示简化不会改变任务绑定和协议执行。选择器复用 Design System 的视口自适应规则；
6. **高级选项**：超时秒数、misfire 宽限秒数；
7. **提交**：“取消”“保存任务”。

视觉层级使用单一滚动 body、细分隔线和固定 footer；任务内容是主要编辑区，模型与高级选项默认折叠。Design System 只改变表现和 draft 交互，不改变 Core schedule、Renderer RFC3339 转换或保存协议。

Agent 输入中的 `/`、`@` 候选说明同样必须留在弹窗可见区域，不能被表单滚动容器裁切；文字和标记对齐遵守[消息输入与编辑](../../01_桌面工作台/消息输入与编辑/需求文档.md)。

项目、日期时间和时区选择器在窗口边缘应自动换向并收缩到可用空间，候选列表或日历在自己的弹层内滚动。打开、筛选和滚动选择器不得新增整页滚动条，也不得改变工作台或编辑器的横向位置。搜索框须在弹层定位完成后聚焦；Escape 只关闭当前选择器，保留外层编辑器和草稿。


首版每任务最大并发固定为 1，不在 UI 暴露伪可配的 `max_concurrency > 1`。全局最多同时执行 2 个 Agent 定时任务；额外到期项进入有界队列，超过其 misfire 宽限后记为 skipped。

### 从模板创建

点击“从模板创建”打开宽度约 860px 的模板窗口：

- 顶部文案“先选内置模板，再在编辑器里微调关键参数后保存”；
- 分类只包含“循环任务”和“日程任务”；
- 模板卡展示名称、说明、频率和“使用模板”；
- 选择模板后关闭模板窗口，打开与普通创建相同的编辑器；
- 模板只预填字段，绝不自动调用创建 API；
- 用户可以修改名称、时间、项目、profile 和正文；
- 新任务保存 `template_origin`，后续编辑不再受模板变更覆盖。

Qwenpaw 的固定 2026 年 1 月日期在当前时间已经可能过期，Awaken 不能照抄成不可执行数据。Awaken 保留模板形态和内容，但在用户每次选择时基于所选时区生成严格晚于当前时间的默认值。

### 编辑、启停、删除和立即执行

- 启停使用 version CAS；乐观 UI 失败后回滚 Core 返回的真实状态。

多个本地存储实例先后编辑同一任务时，旧版本必须被拒绝，不能覆盖新修改。执行状态保存失败时不会广播成功完成或发送成功提醒；用户会收到保存失败通知，应检查磁盘后重启恢复，并在重试业务操作前核对实际结果。重启将未封口的执行标为中断，不自动重跑已可能产生副作用的执行。
- 编辑只影响后续触发；已经开始的 execution 使用开始时快照。
- 任务运行中禁止删除；先取消或等待结束。删除需要确认并创建 tombstone，UI 立即从 active 列表移除。
- “立即执行”需要二次确认，允许对暂停任务执行；成功、失败、取消以及并发满后排队超时都不消耗日程次数或推进计划时间，不会让尚未到期的日程提前完成。
- 同一任务已经运行时，新的 idempotency key 返回 `TASK_ALREADY_RUNNING`，不能悄悄排第二次；相同 key 的网络重试返回原 execution，即使 worker 仍在收尾也不得随机冲突。
- 打开执行记录显示最近 50 条，按 `scheduled_for/started_at` 倒序；错误只显示清洗后的 code/message。

### 专属线程

- 每个任务第一次执行时由 Core 建立稳定专属 thread，`source="scheduled_task"`，项目归属为任务的 `project_id`。
- `StartScheduledRun` 一旦返回真实 `run_id/thread_id`，executor 必须在等待 terminal 之前报告启动身份；Scheduler 立即绑定 task ↔ thread、以同一 execution ID 追加 running-with-identity 记录并发布携带 `project_id/run_id/thread_id` 的 `execution_started`。
- 专属 thread 名称使用任务名；任务重命名后同步 thread 标题，但用户后来手工改过标题时不覆盖。
- 同一任务历次执行继续同一 thread，以便 Agent 使用该任务自己的历史；不同任务不能共享。
- 用户显式删除专属 thread 但保留任务时，下一次执行必须创建新的专属 thread，并仅在任务仍绑定被删除 ID 时以 CAS 更新绑定；不得永久失败，也不得覆盖并发形成的其他有效绑定。
- 普通用户 run 与定时执行同时命中该 thread 时，定时 execution 记为 `skipped/TASK_THREAD_BUSY`，不把内容写到其他 thread。
- 任务删除不自动删除 thread；thread 历史继续遵守现有用户显式删除语义，避免级联丢失交付物。

## 内置模板目录

### 循环任务

| ID | 名称 | 类型 | 默认计划 | 默认内容 |
|---|---|---|---|---|
| `daily_tech_news_brief` | 工作日科技新闻早报 | agent | `30 9 * * 1-5` | 整理今天最值得关注的科技新闻，输出 5–8 条；每条含标题、核心进展、关注原因，最后给出趋势判断 |
| `weekend_relaxation_reminder` | 周末电影推荐 | agent | `0 10 * * 6,0` | 推荐 5 部近期热度高、口碑好的电影，给出类型、看点、适合人群和可得的上映/平台信息 |
| `pomodoro_break_reminder` | 休息提醒 | reminder | `*/25 9-17 * * 1-5` | 持续工作25分钟啦，起来活动一下，喝口水，顺便看看远处放松眼睛～ |
| `pet_care_reminder` | 宠物驱虫/疫苗提醒 | reminder | `0 20 15 * *` | 小提醒：今天记得给毛孩子安排驱虫/疫苗检查喔～ |

### 日程任务

| ID | 名称 | 类型 | 动态默认计划 | 默认内容 |
|---|---|---|---|---|
| `once_text_birthday_reminder` | 生日提醒 | reminder | 所选时区下下一个未来 1 月 1 日 09:00，不重复 | xx在1月1日过生日，别忘了送上祝福～ |
| `once_agent_business_trip_prep` | 出差前天气与行程准备 | agent | 明日 20:00，不重复 | 我明天要出差，请查询目的地天气，并给出穿衣、携带物品和行程准备建议。 |
| `repeat_count_text_medicine_reminder` | 吃药提醒（14次） | reminder | 明日 09:00，每 1 天，限定 14 次 | 注意身体，别忘记吃药哦。 |
| `repeat_count_agent_diet_plan` | 14天饮食计划 | agent | 明日 08:00，每 1 天，限定 14 次 | 我最近在增肌，请为我生成今天的饮食建议。 |
| `repeat_until_text_weekly_meeting` | 两个月周会提醒 | reminder | 下一个未来周五 08:45，每 7 天，截止开始后 8 周 | 15分钟后周会开始。 |
| `repeat_until_agent_weekly_summary` | 周会前工作总结 | agent | 下一个未来周五 08:30，每 7 天，截止开始后 8 周 | 请基于最近一周的 memory，生成本周工作总结，供周会前快速回顾。 |

所有模板默认：

- `enabled=true`；
- `profile_id` 为空，表示触发时先解析 `scheduled_task` 用途 profile，再回退当前默认 ready profile；
- `timeout_seconds=600`；
- `misfire_grace_seconds=600`；
- `template_source="builtin"`；
- 选择模板时使用当前系统 IANA 时区；
- 项目不猜测，必须由用户在保存前显式选择。
