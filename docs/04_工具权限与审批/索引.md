# 04 工具、权限与安全执行

本域拥有 Tool Catalog、provider/capability/dependency、每 run 可用性快照、TaskScope、零审批执行决策、Outcome、当前登录用户 `Bash`、八个模型基础工具，以及保留的 typed 辅助工具。`WorkspaceExecutionBroker` 只服务 `dependency_install`、`git_remote` 和 MCP Artifact bridge；`Bash` 不经过 restricted、supervised、staging 或 broker receipt 路径。

- [工具定义与暴露](工具定义与暴露.md)：目录、provider manifest、环境与工具快照。
- [工具决策、Outcome 与失败监督](工具决策、Outcome与失败监督.md)：默认自动执行、专用 gate、结构化失败与恢复。
- [TaskScope 与路径安全](TaskScope与路径安全.md)：读写根、附件和敏感路径。
- [Bash 本机执行面](Bash本机执行面.md)：当前登录用户 Shell、线程 cwd、前后台任务、真实环境与未观测副作用。
- [Typed 文件工具与可恢复删除](Typed文件工具与可恢复删除.md)：`Read`、`Edit`、`Write`、`Glob`、`Grep` 与 Trash。
- [Artifact 与演示文稿工具契约](Artifact与演示文稿工具契约.md)：当前生成不支持、发布支持、MCP bridge 和历史回放边界。
- [Hook 产品与架构契约](Hook产品与架构契约.md)：user/project/project-local 配置、模型侧 `configure_hook` 自然语言管理、检查详情、摘要信任、run 固定快照、四类同步执行器、十一类事件、阻断/输入更新、耐久回执、恢复、Desktop Hook 设置页及 Skill 显式激活注册。设置页用户可见文案为“钩子”；managed/CLI/Plugin/SDK callback、并行/后台、超限输出 blob、复杂代理闭环、Windows ACL/实机和模型侧 Skill 激活仍不支持或未完成验证。
- [Hook 使用指南](Hook使用指南.md)：面向首次使用者的概念、scope 选择、自然语言配置流程、质量门禁、项目规则加载、敏感文件保护、格式化、通知和输出协议示例；产品事实仍以 Hook 产品与架构契约为准。
- [验收](验收.md)：自动化、平台矩阵和真实 Desktop 验收。

受控 `memory` 当前作为内建辅助工具进入 run 固定快照，不属于八个模型基础文件/搜索工具；已实现 action、Markdown 根、Dream maintenance 边界和剩余验收缺口见 [11 长期记忆](../11_长期记忆/索引.md)。

root-only `archived_history` 也属于内建辅助工具：它以 `thread_id` 访问 Runtime-owned archived metadata 与有界 SemanticJournal 页面，不开放 `~/.awaken` 文件路径；完整产品合同见 [01 会话归档设计契约](../01_桌面工作台/左侧栏/会话归档设计契约.md)。

正式 `subagent` 当前作为 root-only 内建编排工具进入 run 固定快照，支持 `explore/plan/review/general` 的 `spawn/status/wait/cancel/message`；只读角色隐藏 mutation 工具，`general` 可继承不超过父权限的写工具。任务状态、并发、事件和 Desktop 产品语义由 [02 原生 Subagent 产品与架构契约](../02_主智能体闭环/原生Subagent产品与架构契约.md) 唯一拥有。

深度研究 child 的工具面是父快照与内建 `Read/Glob/Grep/WebSearch/WebFetch` 的交集；研究 child 额外禁用 Bash、mutation、Memory 与所有动态 provider。只有成功的 `Read` / `WebFetch` host receipt 能建立 evidence，verifier 必须重新读取相同 locator 才能维持结论。研究产品约束见 [16 深度研究](../16_深度研究/索引.md)。不得把 `WebSearch` snippet 或 MCP `readOnlyHint` 写成已具备 URL 核验或研究授权。

主 run 当前支持 root-only `update_plan` 内建辅助工具和原子快照；该工具不读写 workspace 或外部系统，Subagent child 不暴露。与 Subagent/定时任务的边界及产品语义由 [02 运行计划与任务进度设计契约](../02_主智能体闭环/运行计划与任务进度设计契约.md) 唯一拥有。
