# PPT QA 清单

## 内容

- 页数、顺序、章节、标题和备注完整；
- 数字、单位、时间范围和来源正确；
- 无 lorem、TODO、xxxx、待填、模板说明；
- 隐藏页没有无意泄露的旧内容。

## 结构

- PPTX ZIP 无非法路径、重复部件、链接或特殊文件；
- 必需的 presentation、relationship、content type 部件存在；
- presentation 中注册的每个 slide relationship 都存在；
- 没有未注册的孤立 slide；
- slide 中的 shape ID 唯一；
- chart 引用的轴都已声明；
- 堆积图不使用 PowerPoint 会拒绝的标签位置；
- 模板改稿新增的问题与原模板问题分开报告。

## 视觉

- 每页完整查看，优先检查文字裁切和溢出；
- 不重叠、不穿字、不贴边；
- 相似元素对齐，间距一致；
- 正文足够大，标题与正文有明显层级；
- 图表标签、颜色和单位可读；
- 图片比例正确、分辨率足够；
- 来源、页脚、页码不与内容碰撞；
- 字体替代后的布局仍可靠。
