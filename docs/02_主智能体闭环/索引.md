跨 thread Markdown Memory、主模型 selector recall snapshot、compact 后预算复位、主动记忆指导、Auto Dream 调度和 Dream task 重启恢复已实现；原生 Subagent 已有首阶段运行时，但 child 尚不继承父 `MemoryRecallSnapshot`，因此 child recall 仍是后置约束。原生 Subagent 的 parent/child identity、任务编排和 UI 合同见 [原生 Subagent 产品与架构契约](原生Subagent产品与架构契约.md)，Memory 当前事实与后置约束进入 [11 长期记忆](../11_长期记忆/索引.md)，不能由 thread 历史或压缩摘要替代。
