## Awaken 当前接入

- provider ID：`deepseek`；access type：`api`。
- Chat Base：`https://api.deepseek.com`；Messages Base：`https://api.deepseek.com/anthropic`。
- 当前 catalog 声明 Responses，Base 同为 `https://api.deepseek.com`；官方当前允许 `deepseek-v4-flash`、`deepseek-v4-pro` 与实验性的 `deepseek-v4-flash-vision-exp` 使用该协议。
- 默认模型 `deepseek-v4-pro`；目录 `GET /models`，余额 `GET /user/balance`。

## 鉴权、端点与模型

- Chat 使用 Bearer；Messages 在 Awaken 当前 route 使用 `x-api-key`。
- Chat endpoint 与 Models/Balance 管理 endpoint 不同；余额成功不证明某模型可调用。
- 精确模型 ID、context/output、thinking 和价格以当前 pricing/model/API 页为准。
- Responses 使用同一 Base URL 下的 `/responses`；模型候选与能力仍按官方当前逐模型合同收窄。

## 上下文、多模态与工具

- Chat 是 stateless：客户端每轮发送所需历史；这与 Awaken 本地 transcript 模型一致。
- tools、图片、PDF 等必须以 exact model + Chat/Messages 官方文档为准；未确认的能力标 unknown。
- Anthropic 兼容是子集，不能自动继承 Claude 原生 PDF、cache_control 或 beta features。
- Responses 当前是 stateless 子集：V4 Flash 与 V4 Pro 支持 function/web search 等明确列出的工具；图片输入仅由 `deepseek-v4-flash-vision-exp` 的指定 content part 支持。接口不提供服务端 `previous_response_id`/conversation authority，其他兼容字段以官方表为准。

## 提示词缓存

- DeepSeek 官方为相同前缀提供自动上下文缓存，不需要请求私有字段。
- Awaken Chat 对 exact DeepSeek route 使用 `automatic_prefix_no_request_fields`。
- 解析 prompt cache hit/miss token；hit + miss 构成输入口径，缺失不折 0。
- Messages 兼容入口是否返回相同缓存字段要以官方与实测为准，不能直接继承 Chat。

## 推理开启关闭

- 官方 Thinking Mode 使用当前 `thinking`/`thinking.type` 合同启用或禁用，按模型页复核。
- Awaken 当前只对 exact DeepSeek Chat route/model 白名单发送 `thinking_type`；Responses 通过 `reasoning.effort` 控制强度，不继承 Chat 私有开关。
- 辅助请求关闭 reasoning 时必须验证实际 wire 和返回，不能只检查 HTTP 200。

## 推理强度

- 当前官方模型可能把多个通用 effort 标签归并为较少的有效档位。
- Awaken 当前对 `deepseek-v4-pro` 与 `deepseek-v4-flash` 展示统一 `high | max`，默认 high；不展示伪 low。
- effort 与 thinking 开关、缓存分别建模；价格快照也要按 exact model 更新。

## 用量、余额、限流与套餐

### 用量查询合同

- A 类：Chat usage 包含输入、输出和缓存 hit/miss；Awaken 当前为官方直连 exact model 保存带日期价格快照并计算美元成本。
- B 类：`GET /user/balance` 使用与推理相同的 DeepSeek API Key 和 Bearer 鉴权，返回 `is_available` 以及按币种拆分的总余额、赠送余额和充值余额。
- 凭据：同一个 DeepSeek API Key；endpoint 属于明确公开的账户管理 API，不需要额外 Admin Key。
- Awaken 当前：已接入 `/user/balance`，查询失败、无权限或限流时不得显示成余额为 0。

- 价格极易变化，更新 `connectionPricing`/Core pricing 时必须带生效日期、币种、每百万 token 单位和官方 URL。
- rate limit 可能按账户并发而非固定 RPM，遵循当前官方说明和 retry 行为。
- DeepSeek 网页产品订阅与 API 余额不是同一账户合同。

## Awaken 落地规则

- Responses 向官方当前支持且已建模的 `deepseek-v4-flash` 与 `deepseek-v4-pro` 提供候选；实验视觉模型即使由实时目录出现，也不在缺少 exact capability 时继承图片输入能力。
- Chat 自动缓存不注入额外字段，保持前缀 byte-stable 并正确归一化 hit/miss。
- Messages 只采用 DeepSeek 官方兼容范围，不照搬 Anthropic 原生 capability。
- 价格更新必须同任务更新代码、测试、正式成本文档和本供应商资料。
