# 桌面宠物 · 实现方案

本文说明代码职责、数据与接口、异常恢复和验证方法。功能范围及用户操作见[需求文档](需求文档.md)。

## 架构

```text
Awaken packaged pets -> BuiltinPetImporter
Codex custom packages -> CodexPetImporter
  -> PetStore (<userData>/data/pets + config/pets.json)
  -> Electron Main / PetWindowManager
  -> pet-overlay preload
  -> PetOverlay renderer

Workbench runtime state
  -> PetActivityProjector
  -> Electron Main
  -> PetOverlay renderer

Settings > Pets
  -> Desktop preload bridge
  -> Electron Main
  -> PetStore / PetWindowManager
```

| 层 | 唯一职责 |
|---|---|
| `apps/desktop/src/shared/pets.ts` | IPC/types、sprite常量、TTL和settings contract |
| Electron Main importer/store/validator | 文件发现、校验、复制、catalog/settings持久化 |
| `PetWindowManager` | BrowserWindow、位置/尺寸、screen、shape、IPC、runtime cancel |
| Workbench renderer projector | thread/run/gate状态投影为session activity |
| Pet overlay renderer | sprite、hover/drag/resize、bubble和本地交互 |
| preload | 最小隔离bridge |
| Go runtime | 不感知宠物 |
| Design System | 提供 Settings 宠物视图等纯 UI；preview 由 Desktop 注入，不读 Electron、目录或文件 |

## Activity状态

业务状态：

```ts
type PetSessionStatus = "idle" | "running" | "waiting" | "failed" | "review";
```

映射：

- approvals/userQuestions 非空，或 thread approvalCount>0 -> waiting；
- run `running|cancelling` -> running；
- run `error|cancelled` -> failed；
- run `finished` -> review；
- 无上述状态 -> idle。

多session优先级：

```text
waiting > failed > review > running > idle
```

同优先级按 `updatedAtMs` 新到旧排序。active thread的subtitle优先当前assistant preview，其次active step、last tool decision、waiting提示；最多约96字符。

## Sprite状态与优先级

九状态：

| row | state | frames | 触发 |
|---:|---|---:|---|
| 0 | idle | 6 | 无业务活动 |
| 1 | running-right | 8 | 向右拖动 |
| 2 | running-left | 8 | 向左拖动 |
| 3 | waving | 4 | 首次wake且无更高业务状态 |
| 4 | jumping | 5 | hover |
| 5 | failed | 8 | failed通知 |
| 6 | waiting | 6 | waiting通知 |
| 7 | running | 6 | running通知 |
| 8 | review | 6 | review通知 |

本地交互优先：drag方向 > hover；resize保持当前业务态。业务优先由通知排序决定。禁止把jumping解释为成功或把waving用于普通业务通知。

`idle`帧时长按6倍播放并无限循环；非idle播放3轮后进入idle loop。`prefers-reduced-motion`显示当前状态首帧。

## 生命周期

- Windows/Linux关闭主窗口触发app quit，pet随before-quit dispose。
- macOS关闭主窗口保留app惯例；显式退出时dispose。
- before-quit先停止runtime/subscriptions/project worker，再dispose pet并exit。
- Tuck Away只hide并保存placement，应用和选择仍在。

## 异常与恢复

| 场景 | 行为 |
|---|---|
| 无selected pet | Wake禁用；Main不创建window |
| selected pet从catalog消失 | 清空选择、关闭overlay并持久化 |
| overlay加载/always-on-top漂移 | watchdog恢复；不影响主Workbench |
| display移除 | clamp到可用display |
| renderer异常bounds | Main sanitize/cap |
| runtime不可用时Stop | 结构化错误留在Main日志/UI上下文，不把宠物崩溃 |
| source package删除 | 使用Awaken副本并显示warning |

## 来源

Awaken 的内置宠物位于开发树 `apps/desktop/resources/pets/<pet-id>`，打包后位于 Electron `resources/pets/<pet-id>`。应用每次启动时先校验内置包，再原子复制或更新到 Awaken userData；运行时不直接依赖安装包资源路径。

Awaken 还可选扫描 Codex 自定义包：

```text
${CODEX_HOME:-$HOME/.codex}/pets/<pet-id>/
  pet.json
  spritesheet.webp|spritesheet.png
```

Windows默认 `%USERPROFILE%\.codex\pets`。`CODEX_HOME`非空时优先。扫描只看 `pets/*/pet.json` 一层，跳过dot目录，不递归，不读取cache、avatars、Codex安装目录或远程资源。

Awaken不把Codex源当长期依赖；合法包复制到：

```text
<userData>/data/pets/
  index.json
  <pet-id>/
    pet.json
    spritesheet.png|webp
```

设置写入 `<userData>/config/pets.json`。

## 源manifest

```json
{
  "id": "my-pet",
  "displayName": "My Pet",
  "description": "A short sentence.",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.webp"
}
```

规则：

- id/displayName/description/spritesheetPath必填且非空白；
- id仅小写字母、数字、连字符；
- spriteVersionNumber缺省1，只接受1或2；
- displayName>64或description>256产生warning，不直接拒绝；
- folder name与id不同产生warning；
- spritesheetPath必须相对、不能 `..` 逃逸；
- realpath必须仍在pet dir内，拒绝symlink逃逸；
- manifest最大64KiB，spritesheet最大16MiB；
- 图片只接受PNG/WebP。

## Atlas

共同cell：192x208，8列。

| version | 总尺寸 | grid | 当前播放 |
|---:|---|---|---|
| 1 | 1536x1872 | 8x9 | rows 0–8 |
| 2 | 1536x2288 | 8x11 | rows 0–8；9–10保留 |

v2 rows 9–10按16个look direction排列：000、022.5、045、067.5、090、112.5、135、157.5、180、202.5、225、247.5、270、292.5、315、337.5。Awaken导入但当前不播放。

渲染必须按version计算Y百分比和sheet rows：v1 `row/8`，v2 `row/10`；CSS background-size为 `800% rows*100%`。缺version按v1归一，不能用9行公式渲染v2。

## Awaken内部manifest

```ts
type PetManifest = {
  schemaVersion: 1;
  id: string;
  sourceId: string;
  displayName: string;
  description: string;
  spriteVersionNumber: 1 | 2;
  spritesheetFile: "spritesheet.png" | "spritesheet.webp";
  source: "awaken-builtin" | "awaken-local" | "codex-custom";
  sourcePath?: string;
  sourceFingerprint?: string;
  importedAt?: string;
};
```

Codex custom的Awaken id等于source id，不加namespace；来源由source字段区分。catalog、summary、bootstrap、settings preview和overlay都必须透传spriteVersionNumber。

## 导入事务

### 内置包

1. 根据 dev/packaged 形态定位 `resources/pets`；
2. 按路径排序扫描并执行与自定义包相同的 manifest/path/format/size/dimensions 校验；
3. 以 `source: "awaken-builtin"` 复制到 staging 并原子替换；
4. fingerprint 未变时跳过 sprite copy，版本升级后资源变化则更新 Awaken 副本；
5. 不修改用户选择，不自动 Wake。

### Codex 自定义包

1. detect Codex Home；
2. 按路径排序扫描candidate；
3. validate JSON/path/format/size/dimensions；
4. 同source id只保留排序第一项，其余记录conflict；
5. 计算source fingerprint；
6. `PetStore.importOrUpdatePet()` 复制到staging并原子替换；
7. 成功后更新catalog；
8. source消失时保留Awaken副本并标记 `#source-missing`；
9. 广播catalog changed；若当前浮窗已开且选择仍有效则热刷新。

fingerprint包含图片hash、source/sourceId、displayName、description、spriteVersion和扩展名；这些metadata变化会改变fingerprint并进入更新复制链。fingerprint未变时，当前只有不参与fingerprint的 `sourcePath` 等catalog字段可能单独更新并跳过sprite copy。新损坏版本不能覆盖上一份成功副本。

## 选择必须保持的规则

- 自动导入、手动刷新不写 `selectedPetId`；
- 不自动Wake；
- Codex源删除不清Awaken副本/选择；
- 当前选择不可用且catalog确实不含该id时，初始化清空选择和overlayOpen；
- Codex当前选择和全局state永不作为输入。

## 安全边界

- 包仅含数据，不执行代码；
- HTML/JS/SVG不能成为sprite；
- renderer只拿 `awaken-pet://asset/<petId>/spritesheet?v=...` 受控URL，不拿任意路径；
- protocol parser拒绝额外path segment；
- Main重新校验IPC参数；
- importer不修改Codex任何文件；
- 单个坏包隔离，不阻断Desktop启动或其他包；
- 当前未做逐像素透明度校验，validator明确warning；不能宣称已验证所有cell透明质量。

## 当前本地模板边界

Main内部 `createPet` handler可创建一个透明PNG本地模板和catalog记录，用于手工替换sprite后调试。Settings当前没有入口，它不调用hatch-pet、不生成角色、不做视觉QA，也不写Codex。因此正式产品能力仍为“不支持创建宠物”。

## 异常

| 场景 | 结果 |
|---|---|
| Codex Home/pets缺失 | 空列表，不阻塞启动 |
| JSON/字段/路径非法 | failed report |
| PNG/WebP无法解码/尺寸不符 | 拒绝 |
| duplicate id | 首项保留，其余conflict |
| source删除 | Awaken副本可用，warning |
|新版本损坏 | 保留旧副本 |
| catalog损坏项 | normalize时忽略；selected失效则关闭overlay |

## 浮窗的实现

Electron BrowserWindow：frameless、transparent、背景色固定透明、alwaysOnTop(screen-saver)、skipTaskbar、no shadow、non-resizable；显示用 `showInactive()`。主窗口主题切换只更新主窗口背景，不遍历覆盖宠物浮窗。macOS设置visible-on-all-workspaces/fullscreen并保持主app Dock身份。

- renderer ResizeObserver上报bubble+pet bounds；
- Main sanitize/min/max并以右下锚点resize，气泡出现/消失不移动宠物；
- Windows/Linux设置shape为交互区域；其他平台平时ignore mouse，hover/drag/resize/bubble时启用；
- recovery watchdog每3秒恢复always-on-top等可见性；
- 初次位置为主屏右下24px；
- screen add/remove/metrics change时clamp并持久化。
