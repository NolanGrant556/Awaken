# Excel 读取与分析

选择满足当前问题的最轻路线：快速文本浏览可用 markitdown/pandas，需要坐标、公式或样式时用 openpyxl；批量清洗和聚合用 pandas。按 [依赖与执行](依赖与执行.md) 探测实际 route。

阅读公式模型时分两次加载：公式模式保留公式，`data_only=True` 只读缓存；后者不能保存。缓存缺失或过期时限定数值结论，只有任务确需当前计算结果时才在新副本上重算，不因文件含公式就重算原件。

分析多工作簿或脏数据前，抽样确认表头、列类型、空值、混合状态文本、日期和零分母。可用 `scripts/inspect_workbook.py` 建立输入剖面；保留数值转换失败的样本，不直接 float(value)、不猜固定表头行。并行分析继承这些证据边界。

纯读取回答问题并说明 sheet/行列或抽样范围即可，不要求保存工作簿、刷新缓存或发布文件。
