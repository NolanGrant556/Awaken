# AwakenSelect

`AwakenSelect` 是 Awaken 单选列表的统一视觉与交互组件。适用于模型、工具等需要展示 Awaken 自有列表样式的单选字段；父级拥有业务选项、选中值和保存逻辑，组件只负责触发器、列表、键盘操作与选中态。

## 规则

- 产品内需要自定义列表外观的单选字段使用本组件，不回退为操作系统原生 `<select>` 菜单。
- 选项列表使用统一的表面、边框、圆角、选中态、勾选图标与透明滚动轨道。
- 菜单保留在调用方当前浮层内：默认优先向下，调用方可用 `preferredPlacement` 指定更适合当前容器的首选方向；首选方向空间不足时切到空间更多的一侧。窗口缩放或祖先滚动后必须重新计算方向，菜单继续使用限高内部滚动。
- `disabled`、空选项和占位文案不得改变控件尺寸。
- 只通过 props 输入并通过 `onValueChange` 输出，不读取 Electron、runtime 或业务 store。
