# 当前中间区域功能与交互逻辑清单

## 1. 容器与结构

| 区域 / 模块 | 当前承载功能 | 用户交互逻辑 | 状态 / 数据来源 | 主要实现位置 |
|-------------|--------------|--------------|-----------------|--------------|
| `WorkbenchShell` | 承载中间工作区与右侧 inspector 的整体布局 | sidebar / inspector 折叠或改变宽度时，中间区域随布局变化 | `inspectorCollapsed`、`inspectorWidth`、`sidebarWidth` | `App.tsx` |
| `RunStage` | 中间区域唯一滚动、定位、overlay、composer 容器 | 运行态接收滚动事件；承载 overlay 与 dock composer | `showCenterComposer`、`setRunStageScrollElement`、`handleRunStageScroll` | `App.tsx`、`useRunStageScrollController.ts` |
| `RunStage` children | 在空态与运行态之间切换主内容 | 空态显示 center composer；非空态显示 ExecutionFeed | `showCenterComposer` | `App.tsx` |
| `RunStage` overlay | 承载中间区域浮层 | 显示 notice toast、turn marker rail | `renderNoticeToast()`、`showTurnMarkerRail` | `App.tsx` |
| `RunStage` composer slot | 承载运行态 dock composer | 非空态显示 `ComposerDock`；空态不挂 dock composer | `showCenterComposer` | `App.tsx` |
| `ExecutionFeed` | 承载 narrative / turn 内容 | 用户阅读执行过程、工具轨迹、审批历史、回答 | `narrativeSections` | `App.tsx`、`workbenchPresentation.ts` |
| `ComposerDock` | 承载运行态输入区 | 用户继续输入、停止运行、处理 approval、查看模型与上下文信息 | `composerBarState`、`composerMetaItems`、`activeApproval` | `App.tsx` |

## 2. 主显示状态

| 状态 | 出现条件 | 中间区域显示内容 | 用户可执行动作 | 状态切换触发 |
|------|----------|------------------|----------------|--------------|
| 空态 center composer | 无 narrative 且无 active run | `TaskWelcome`、runtime panels、active approval prompt、`ComposerBar variant="center"` | 输入 prompt、发送任务、切换模型、查看 workspace / context meta | 发送任务后进入运行态 |
| 运行态 dock composer | 有 narrative 或 active run | `ExecutionFeed`、`ComposerDock`、overlay toast、可能显示 turn marker rail | 阅读输出、继续输入、停止 run、审批、滚动历史、点击 marker | run 完成后仍保持历史态 |
| 历史线程态 | 选择已有 thread 并 replay transcript | 重放后的 ExecutionFeed、dock composer | 阅读历史、继续在同一 thread 发送新 prompt | 选择 thread、replay transcript |
| 忙碌态 | phase 为 starting / running / reconnecting / cancelling | dock composer 处于 stop 模式，ExecutionFeed 持续更新 | 点击 submit 按钮会取消 run | run 进入终态 |
| runtime 异常态 | supervisor crashed、starting 或 run error | composer 附近显示 runtime panel | 等待启动、重启 Awaken、查看错误 | runtime status / error 变化 |

## 3. Composer 输入区

| 功能点 | 当前承载位置 | 用户交互逻辑 | 禁用 / 状态规则 | 主要实现位置 |
|--------|--------------|--------------|-----------------|--------------|
| 输入 prompt | center composer / dock composer | 用户输入任务文本 | busy、Desktop 未 ready、workspace 无效时禁用 | `useComposerLifecycle.ts` |
| 发送任务 | `ComposerBar` submit | 非 busy 时点击 submit 发起 run | prompt 不能为空；workspace 必须是有效绝对路径 | `handleComposerSubmit()`、`handleSubmit()` |
| 停止任务 | `ComposerBar` submit | busy 时 submit 变为 stop，点击后取消 run | starting / running / reconnecting / cancelling 时启用 stop 模式 | `handleCancel()` |
| 清空输入 | 发送成功前后 | 发送开始后清空 composer | startRun 失败时恢复原输入 | `clearComposerValue()`、`restoreComposerValue()` |
| 聚焦输入 | composer focus request | 新建任务、发送后请求 focus | 通过递增 `composerFocusRequest` 触发 | `requestComposerFocus()` |
| 添加上下文 | composer add context | 点击后当前只显示未接线提示 | 尚未接入真实 picker | `handleAddContext()` |
| 模型选择 | composer meta item | 用户打开模型菜单并切换 enabled profile | 无模型时显示“请点击头像配置模型”且 disabled | `handleSelectModelProfile()` |
| 添加模型入口 | 模型菜单 footer | 用户点击后打开模型设置 | 始终作为模型菜单 footer action | `setModelSettingsOpen(true)` |
| workspace 显示 | composer meta item | 展示当前项目 / workspace label | 随 selected project 变化 | `composerMetaItems` |
| context window 显示 | composer meta item | 展示当前 context usage | 来自 runtime inspector summary | `contextUsageMeta()` |

## 4. Runtime Panels 与 Toast

| 功能点 | 当前承载位置 | 用户交互逻辑 | 出现条件 | 主要实现位置 |
|--------|--------------|--------------|----------|--------------|
| Awaken needs restart panel | center / dock composer stack | 用户看到需要重启提示 | supervisor status 为 crashed | `composerRuntimePanelsForStatus()` |

## 5. 任务提交与运行状态

| 流程节点 | 当前功能 | 用户交互逻辑 | 状态变化 | 主要实现位置 |
|----------|----------|--------------|----------|--------------|
| 提交前校验 | 校验 Desktop、prompt、busy、workspace | 用户点击发送后先做本地校验 | 失败时显示 notice 或 runtime panel | `handleSubmit()` |
| workspace 校验 | 调用 runtime 验证 workspace | workspace 无效则阻止发送 | 显示 validation error | `runtimeClient.validateWorkspace()` |
| run requested | 把 prompt 写入 narrative | 用户发送后立刻看到自己的 prompt | dispatch `run/requested` | `runtime/reducer.ts` |
| run created | runtime 返回 run/thread | 用户进入真实运行流 | dispatch `run/created`、`run/threadAdded` | `handleSubmit()` |
| run subscription | 订阅 run stream | 输出持续进入 ExecutionFeed | `runtimeClient.subscribeRun` | `handleSubmit()` |
| persisted run | 保存 runId | app 重启后可尝试恢复运行 | 写入 `localStorage.awaken:runId` | `handleSubmit()` |
| cancel requested | 用户点击 stop | run 进入 cancelling | dispatch `run/cancelRequested` | `handleCancel()` |
| cancel sync | runtime 返回取消后的 run | 用户看到停止后的终态 | dispatch `run/cancelSync` | `handleCancel()` |
| create failed | startRun 失败 | 恢复输入并显示错误 | dispatch `run/createFailed` | `handleSubmit()` |

## 6. ExecutionFeed 与 Turn

| 功能点 | 当前承载方式 | 用户看到什么 | 交互逻辑 | 主要实现位置 |
|--------|--------------|--------------|----------|--------------|
| narrative 可见项 | committed items + active item | 正在生成和已完成内容 | `planning` 当前被过滤不显示 | `visibleNarrativeItems` |
| lead items | 第一个 prompt 前的 item | 非 turn 归属的前置信息 | 居中限制到 turn 内容宽度 | `groupNarrativeByTurns()` |
| turn 分组 | 每个 prompt 开启一个 turn | prompt 与后续输出形成一组 | prompt 后 item 进入该 turn body | `groupNarrativeByTurns()` |
| turn section | `section.execution-turn-section` | 每轮任务的完整叙事区块 | 用 `data-execution-turn-id` 支撑滚动定位 | `App.tsx` |
| prompt header | `.execution-turn-header` | 用户 prompt bubble | active turn header sticky | `App.tsx`、`workbench.css` |
| turn body | `.execution-turn-body` | Thought、工具、审批、文件、回答 | 内容增长触发布局与 follow 判断 | `App.tsx` |
| latest turn | `execution-turn-section-latest` | 最新 turn 可获得最小高度 | 用于 prompt anchor 与 composer 避让 | `useRunStageScrollController.ts` |
| active turn | `execution-turn-section-active` | 当前定位 turn 的 prompt sticky | 随滚动或 marker 点击变化 | `useRunStageScrollController.ts` |

## 7. Narrative Item 类型

| item kind | 渲染组件 / 结构 | 用户看到什么 | 交互逻辑 | 数据来源 |
|-----------|-----------------|--------------|----------|----------|
| `thinking` | `ThoughtTrace` | 推理 / 思考文本 | active / done 状态展示 | reasoning AG-UI events |
| `answer` | `AssistantMessage` | markdown 回答 | final done 时显示 footer | text message events / run finished |
| `exploring` | `ToolTraceGroup` | 多个只读工具动作聚合 | 展示 action status 与 detail | read_file / list_files / grep_search 等 |
| `tool` | `ToolTraceLine` | 单个工具调用轨迹 | 展示 active / done / error | tool call events |
| `approval` | inline `ApprovalCard` | 历史审批卡 | active approval 已在 composer 显示时避免重复 | approval events |
| `fileChange` | `FileChangeSummary` | 文件变更摘要 | 展示文件列表与状态 | artifact / file change projection |
| `compactBoundary` | compact boundary line | context compact 边界 | 只展示 started / finished / failed 边界 | compact events |

## 9. 滚动、锚定与 Follow

| 功能点 | 当前逻辑 | 用户交互表现 | 状态 / 判断 | 主要实现位置 |
|--------|----------|--------------|-------------|--------------|
| 绑定滚动容器 | 非 center 状态设置 scrollRef / onScroll | 运行态中间区域可滚动 | `showCenterComposer ? undefined : setRunStageScrollElement` | `App.tsx` |

| 用户上滚暂停 | wheel 向上、scrollTop 变小 | 用户阅读历史时不强拉回底部 | `latestOutputFollowPausedByUserRef` | `pauseLatestOutputFollowForUser()` |
| pointer 暂停 | pointerdown 后暂停 follow | 用户点击 / 操作历史内容时退出 follow | direct user input | `setRunStageScrollElement()` |

## 11. Turn Marker Rail
